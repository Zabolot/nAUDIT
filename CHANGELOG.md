# CHANGELOG nAUDIT

## [2.1.0] - 2025-01-15 (Текущая версия)

### 🎨 Добавлено

#### Граф-визуализация проекта (Новое в v2.1.0)
- **ErrorVisualizationWidget**: Комбинированный визуализатор ошибок
  - Три режима просмотра: Дерево, Граф, Разделённый
  - Переключение между режимами одной кнопкой
  - Всё в одной вкладке "🌳 Ошибки"

- **GraphVisualizerWidget**: Интерактивная граф-визуализация
  - Узлы = файлы проекта
  - Размер узла = количество строк кода
  - Цвет узла = максимальная серьезность ошибок
  - Текст на узле = имя файла + счётчик ошибок
  - Групповая визуализация по папкам
  - Интерактивное управление: зум, панировка, перемещение
  - Панель фильтрации и управления

- **Система управления**:
  - Фильтр по серьезности ошибок
  - Масштабирование узлов (50-200%)
  - Переключение метак и связей
  - Кнопка обновления графа

- **PyQt6-WebEngine**: Поддержка web-визуализации
  - Современная цветовая палитра HSV для папок
  - Физика графа для автоматического позиционирования
  - HTML5 интерактивность через pyvis

### 📚 Документация

- `docs/GRAPH_VISUALIZATION_GUIDE.md` - Полное руководство по граф-визуализации
- Обновлены примеры использования в `docs/USER_GUIDE_V4_1.md`

### 🔧 Улучшения

- Интеграция ErrorVisualizationWidget в main_window_v4
- Оптимизирована производительность при загрузке больших проектов
- Улучшена цветовая кодировка узлов

### 📦 Зависимости

- Добавлено: `PyQt6-WebEngine>=6.0`
- Обновлено: `pyvis>=0.3`
- Обновлено: `networkx>=3.0`

## [2.0.0] - 2025-01-13

### 🎉 Добавлено

#### GUI приложение
- Полнофункциональное графическое приложение на PyQt6
  - Вкладка "Аудит" для выбора проекта и запуска анализа
  - Вкладка "Результаты" с оценкой и рекомендациями
  - Вкладка "Справка" со встроенной документацией
- Современный минималистичный дизайн с цветовой схемой
- Асинхронное выполнение аудита без блокировки интерфейса
- Прогресс-бар с детализацией по фазам
- Логирование всех событий в реальном времени
- Возможность отмены аудита в любой момент

#### Менеджер аудита (AuditManager)
- Асинхронное управление процессом аудита
- Система обратных вызовов (callbacks) для GUI
- Поддержка многопоточности
- Расчет оценки качества кода (1-10)
- История аудитов с отслеживанием изменений

#### Расширенный анализ кода
- Улучшенная интеграция с pylint (JSON вывод)
- Поддержка flake8 для проверки стиля
- Анализ типов с mypy
- Детальный анализ цикломатической сложности (radon)
- Идентификация функций высокой сложности (> 8)

#### Проверка безопасности
- Расширенная обработка результатов bandit
  - Категоризация по приоритету (HIGH, MEDIUM, LOW)
  - Отслеживание типов уязвимостей
- Улучшенная проверка зависимостей (safety)
- Готовность к интеграции gitleaks

#### Анализ тестов
- Полная поддержка pytest с coverage
- JSON отчеты покрытия
- HTML отчеты для визуализации
- Выявление файлов с низким покрытием (< 50%)

#### Проверка инфраструктуры
- Анализ конфигурационных файлов (.yml, .env и т.д.)
- Docker интеграция (информация об образах и контейнерах)
- SQL анализ с sqlfluff
- Информация об окружении (Python, платформа, переменные)

#### Интеллектуальные рекомендации
- Умная генерация рекомендаций на основе результатов
- Приоритизация проблем (критические, важные, рекомендуемые)
- Конкретные советы по исправлению
- Учет типов и количества обнаруженных проблем

#### Сборка приложения
- PyInstaller интеграция для создания .exe файлов
- Автоматическая сборка с PowerShell скриптом
- Поддержка скрытых импортов
- Однофайловое распределение (one-file)

#### Документация
- Подробное руководство пользователя (USER_GUIDE.md)
- Техническая документация для разработчиков (TECH_GUIDE.md)
- Обновленный README.md с примерами
- Встроенная справка в приложении

#### Скрипты запуска
- `run_naudit.ps1` - быстрый запуск на Windows
- `run_naudit.sh` - быстрый запуск на Linux/macOS
- `build_exe.ps1` - сборка .exe файла
- `setup_project.py` - инициализация проекта

## Примечания версии

### 2.0.0

**Основной переход на GUI приложение**

nAUDIT теперь предоставляет полнофункциональное графическое приложение, которое делает процесс аудита интуитивным и удобным. Новая версия сохраняет совместимость с CLI и добавляет множество новых функций.

**Основные преимущества v2.0:**
- 🎨 Современный интерфейс
- ⚡ Асинхронное выполнение
- 📊 Улучшенная визуализация результатов
- 🚀 Готовый .exe файл для Windows
- 📚 Подробная документация
- 🔌 Расширяемость через плагины

**Миграция с v1.0:**

Все старые команды по-прежнему работают:
```bash
# v1.0 команда
naudit --module . --report-level full

# v2.0 команды
naudit-gui              # Новый графический интерфейс
naudit --module .       # Старый CLI (совместим)
```
