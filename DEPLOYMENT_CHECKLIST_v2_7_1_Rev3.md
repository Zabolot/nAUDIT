## 📋 ТЕСТИРОВАНИЕ (ВЫПОЛНИТЬ)

### Шаг 1: Базовая функциональность
- [ ] Запустить exe: `.\dist\nAUDIT.exe`
- [ ] Открыть папку проекта
- [ ] Запустить аудит
- [ ] Перейти на вкладку "Ошибки и деревья"
- [ ] **Проверить:**
  - [ ] Виден заголовок "❌ РЕЗУЛЬТАТЫ АУДИТА (X ошибок...)"
  - [ ] Список ошибок НЕ пустой (если есть ошибки)
  - [ ] Первый файл выбран и подсвечен
  - [ ] Детали ошибки видны справа

### Шаг 2: Синхронизация Tree ↔ Graph
- [ ] Перейти в режим Split (View → Layout → Split View)
- [ ] Кликнуть на другой файл в дереве
- [ ] **Проверить:** Узел в графе выделяется
- [ ] Кликнуть на узел в графе
- [ ] **Проверить:** Файл выбирается в дереве

### Шаг 3: GPU Detection
- [ ] Проверить статус bar GPU
- [ ] Если GPU есть - должен показываться его тип
- [ ] Проверить логи: `[GPU Detector] GPU detection completed`

### Шаг 4: Проекты без ошибок
- [ ] Открыть чистый проект (без ошибок)
- [ ] Запустить аудит
- [ ] **Проверить:**
  - [ ] Заголовок должен быть зелёным: "✓ РЕЗУЛЬТАТЫ АУДИТА"
  - [ ] Дерево должно показывать ВСЕ файлы (не пусто)
  - [ ] Лист ошибок пустой

### Шаг 5: Большие проекты
- [ ] Открыть проект с 1000+ файлов
- [ ] Запустить аудит
- [ ] **Проверить:**
  - [ ] Нет фризов/зависаний
  - [ ] Дерево построено корректно
  - [ ] Статистика правильна

### Шаг 6: Логирование
- [ ] Открыть: `%USERPROFILE%\.naudit\logs\latest.log`
- [ ] **Ищите эти строки:**
  - [ ] `[Tree Widget] Auto-selecting first file with issues`
  - [ ] `[Tree Widget] Selected and highlighted first file`
  - [ ] `[Tree Widget] Tree built: total_issues=...`
  - [ ] `[GPU Detector] GPU detection completed`
  - [ ] **НЕ должно быть:** исключений или ошибок Python
