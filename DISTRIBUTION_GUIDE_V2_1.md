## 🔧 Решение проблем при запуске

### Проблема 1: Windows показывает предупреждение

**"Защита вашего ПК: Windows потребовала разрешение на запуск этого приложения"**

**Решение:**
1. Нажмите "Run anyway" (Запустить в любом случае)
2. Это появляется, потому что .exe не подписан цифровой подписью
3. Это нормально для индивидуальных разработчиков

### Проблема 2: Файл не запускается

**Проверьте:**
1. Нет ли ошибок диска (попробуйте перезагрузиться)
2. Достаточно ли памяти (4+ GB рекомендуется)
3. Не блокирует ли антивирус (добавьте в белый список)

**Решение:**
```powershell
# Откройте PowerShell и введите:
& "C:\path\to\nAUDIT.exe"
```

Это покажет подробные ошибки, если они есть.

### Проблема 3: Медленный запуск

**Это нормально:**
- Первый запуск может занять 5-10 секунд
- Распаковка из .exe в память
- Инициализация PyQt6 WebEngine

**Решение:**
- Закройте другие приложения
- Убедитесь, что диск не заполнен
- Попробуйте перезагрузиться

### Проблема 4: "Не удаётся найти Python"

**Это НЕ должно происходить:**
- .exe файл содержит всё необходимое
- Python не требуется на компьютере пользователя

**Если это всё же появилось:**
- Это может быть встроенный Python системы
- Скачайте nAUDIT.exe заново
- Попробуйте запустить с администратором

## 🚀 Продвинутое распространение

### Сценарий 1: Корпоративное распределение
```powershell
# Развернуть на всех компьютерах в сети
Copy-Item -Path "\\server\share\nAUDIT.exe" `
          -Destination "C:\Program Files\nAUDIT\" `
          -Force

# Создать ярлык на рабочем столе
$WshShell = New-Object -ComObject WScript.Shell
$Shortcut = $WshShell.CreateShortcut("$env:USERPROFILE\Desktop\nAUDIT.lnk")
$Shortcut.TargetPath = "C:\Program Files\nAUDIT\nAUDIT.exe"
$Shortcut.Save()
```

### Сценарий 2: Автоматическое обновление
```powershell
# Скрипт для проверки новой версии
$currentVersion = "2.1.0"
$latestVersion = Invoke-RestMethod -Uri "https://api.github.com/repos/owner/nAUDIT/releases/latest" | Select-Object -ExpandProperty tag_name
if ($latestVersion -gt $currentVersion) {
    Write-Host "Новая версия доступна: $latestVersion"
}
```
