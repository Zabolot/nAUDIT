## 🚀 Быстрый доступ

### Для новых пользователей

1. Начните с **README.md** для понимания возможностей
2. Прочитайте **QUICK_SUMMARY_v2_1.md** для обзора последних изменений
3. Используйте **docs/USER_GUIDE_V4_1.md** для пошаговых инструкций

### Для разработчиков

1. Изучите **docs/GRAPH_VISUALIZATION_GUIDE.md** для API
2. Посмотрите **docs/TREE_WIDGET_V4_1_ARCHITECTURE.md** для архитектуры
3. Запустите **final_check_v2_1.py** для проверки окружения

### Для администраторов

1. Следуйте **README.md** для установки
2. Используйте **build_exe.ps1** для сборки .exe
3. Читайте **docs/BUILD_SUCCESS.md** при проблемах
