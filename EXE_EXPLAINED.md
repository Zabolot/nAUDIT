# 🚀 Как Работает .exe Система nAUDIT

## Тройной Уровень Запуска

Приложение nAUDIT можно запустить 3 способами:

### 1️⃣ **Способ 1: Исходный код (Python)**

```bash
python -m n_audit.gui.main_app
```

- ✅ Требует: Python 3.10+, все пакеты установлены
- ✅ Быстрое редактирование и тестирование кода
- ✅ Можно дебажить в IDE
- ❌ Зависит от наличия Python и всех зависимостей

**Когда использовать:** Разработка, тестирование, модификация кода

---

### 2️⃣ **Способ 2: Готовый .exe Файл**

```powershell
.\dist\nAUDIT.exe
```

- ✅ **Не требует** Python
- ✅ **Не требует** пакетов
- ✅ Работает на любом Windows
- ✅ Одиночный 34 МБ файл
- ❌ Не редактируется (двоичный формат)
- ❌ Занимает дисковое место

**Когда использовать:** Распространение, установка у пользователей, автономное использование

---

### 3️⃣ **Способ 3: Автоматизированный Запуск (Скрипты)**

```powershell
.\run_naudit.ps1          # Windows
./run_naudit.sh           # Linux/Mac
```

- ✅ Автоматически активирует окружение
- ✅ Проверяет зависимости
- ✅ Удобный запуск одной командой
- ✅ Информативный вывод о процессе

**Когда использовать:** Быстрый запуск, проверка окружения

## 📦 Архитектура .exe Файла

### Что содержит nAUDIT.exe?

```
nAUDIT.exe
├── Python Interpreter (3.12)          ← Встроенный Python
├── PyQt6 Framework                      ← GUI библиотека
├── Analysis Modules                     ← Пакеты анализа
│   ├── radon           (сложность)
│   ├── bandit          (безопасность)
│   ├── safety          (зависимости)
│   ├── pytest          (тестирование)
│   ├── coverage        (покрытие)
│   └── ... остальные
├── Код nAUDIT                           ← Исходный код проекта
│   ├── gui/
│   ├── core.py
│   ├── audit_manager.py
│   └── ...
└── Data & Config                        ← Конфигурация и данные
```

### Как это работает?

1. **Пользователь двойной клик** на `nAUDIT.exe`
2. **PyInstaller запускает встроенный Python**
3. **Python загружает все модули** из архива внутри .exe
4. **Запускается GUI приложение** (`n_audit/gui/main_app.py`)
5. **Пользователь видит окно** и может выбрать проект для аудита

## 🔨 Как Собрать .exe из Исходного Кода

### Способ 1: Автоматический (Рекомендуется)

```powershell
cd G:\CODING\nAUDIT
.\build_exe.ps1
```

### Способ 2: Вручную через Python

```powershell
cd G:\CODING\nAUDIT
.\v.naudit\Scripts\Activate.ps1
python build_exe.py
```

### Способ 3: Прямая команда PyInstaller

```powershell
cd G:\CODING\nAUDIT
.\v.naudit\Scripts\Activate.ps1
pyinstaller --onefile --windowed --name=nAUDIT n_audit\gui\main_app.py
```

### Параметры Сборки

| Параметр | Значение | Описание |
|----------|----------|---------|
| `--onefile` | ✓ | Один файл вместо папки |
| `--windowed` | ✓ | Без консольного окна |
| `--name` | `nAUDIT` | Имя приложения |
| `--hidden-import` | PyQt6, etc | Скрытые импорты |
| `--icon` | `icon.ico` | Иконка приложения (опционально) |

## 🎯 Пошаговое Объяснение Сборки

### Шаг 1: Подготовка

```powershell
# Активируем окружение
.\v.naudit\Scripts\Activate.ps1

# Убеждаемся, что PyInstaller установлен
pip list | grep PyInstaller
```

### Шаг 2: Сборка

```powershell
pyinstaller --onefile --windowed --name=nAUDIT n_audit\gui\main_app.py
```

**Что происходит:**
1. PyInstaller анализирует `n_audit/gui/main_app.py`
2. Находит все импорты (PyQt6, n_audit модули, etc)
3. Рекурсивно собирает все зависимости
4. Копирует Python интерпретатор
5. Создаёт архив со всеми файлами
6. Упаковывает архив в .exe файл

### Шаг 3: Проверка

```powershell
# Проверяем результат
ls -la dist/nAUDIT.exe

# Тестируем
.\dist\nAUDIT.exe
```

### Шаг 4: Распространение

```powershell
# Просто скопируем файл
Copy-Item dist\nAUDIT.exe -Destination C:\Program Files\nAUDIT\
```

**Готово!** Пользователи могут запустить `nAUDIT.exe` без установки Python.

## ⚙️ Технические Детали PyInstaller

### 1. Анализ Зависимостей

PyInstaller использует статический анализ Python кода:

```python
# Этот импорт БУДЕТ найден
import PyQt6

# Этот импорт МОЖЕТ не найтись (динамический)
module_name = "PyQt6"
module = __import__(module_name)

# Решение: используем --hidden-import
# pyinstaller --hidden-import=PyQt6 ...
```

### 2. Скрытые Импорты

Некоторые пакеты импортируются динамически, поэтому нужно указать их явно:

```bash
pyinstaller \
  --hidden-import=PyQt6.QtCore \
  --hidden-import=PyQt6.QtGui \
  --hidden-import=PyQt6.QtWidgets \
  --hidden-import=radon \
  --hidden-import=bandit \
  ...
```

### 3. Размер Файла

```
Минимальный:  10-20 МБ   (только Python + PyQt6)
Типичный:     34-50 МБ   (+ все пакеты анализа)
Максимальный: 100+ МБ    (+ все опциональные пакеты)
```

### 4. Производительность

```
Python Скрипт:    Запуск ~1-2 сек
.exe файл:        Запуск ~3-5 сек (распаковка архива)
После кеша:       Запуск ~1-2 сек (кеш OS)
```

## 🚨 Решение Проблем

### Проблема: ".exe файл не запускается"

**Решение:**
1. Проверьте консоль для ошибок: `nAUDIT.exe` без bg
2. Убедитесь, что PyQt6 установлена в виртуальном окружении
3. Проверьте файл `build/nAUDIT/warn-nAUDIT.txt` на предмет предупреждений

### Проблема: "Ошибка импорта при запуске .exe"

**Решение:**
```bash
# Добавьте скрытый импорт
pyinstaller \
  --hidden-import=название_модуля \
  --onefile --windowed --name=nAUDIT \
  n_audit/gui/main_app.py
```

### Проблема: ".exe слишком большой"

**Решение:**
- Используйте `--onefile` (обычно даже меньше)
- Исключите ненужные пакеты из `requirements.txt`
- Используйте `--exclude-module=numpy` для больших пакетов

### Проблема: "Долгий запуск .exe первый раз"

**Это нормально!** PyInstaller распаковывает архив при первом запуске (~3-5 сек).
Последующие запуски будут быстрее.
