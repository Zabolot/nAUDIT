# 📘 Объяснение системы .exe файла и запуска nAUDIT

## 🎯 Как работает система .exe?

### Общая концепция

nAUDIT может запускаться двумя способами:

```
┌─────────────────────────────────────────────────────┐
│              Как запустить nAUDIT?                  │
├─────────────────────────────────────────────────────┤
│                                                     │
│  1️⃣  БЕЗ установки (требуется Python 3.8+)        │
│      │                                              │
│      ├─ Способ A: Запустить GUI напрямую          │
│      │           python -m n_audit.gui.main_app   │
│      │                                              │
│      └─ Способ B: Использовать скрипт             │
│                  .\run_naudit.ps1                  │
│                                                     │
│  2️⃣  С установкой (создание .exe файла)           │
│      │                                              │
│      └─ Собрать .exe один раз                      │
│         .\build_exe.ps1                            │
│         ↓                                           │
│         dist/nAUDIT.exe ← готово распространять    │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 🔍 Подробное объяснение каждого способа

#### **Способ 1: GUI напрямую (требуется Python)**

```
Вы пишете:           python -m n_audit.gui.main_app
                            ↓
Python интерпретатор
ищет пакет:          n_audit
                            ↓
Находит модуль:      gui/main_app.py
                            ↓
Запускает функцию:   main()
                            ↓
PyQt6 создает окно приложения
```

**Требования:**
- ✅ Python 3.8+
- ✅ Все зависимости установлены (PyQt6, pylint и т.д.)

#### **Способ 2: Скрипт run_naudit.ps1**

```
Вы запускаете:       .\run_naudit.ps1
                            ↓
PowerShell скрипт делает:
  1. Проверяет Python
  2. Создает виртуальное окружение (если нет)
  3. Активирует виртуальное окружение
  4. Устанавливает зависимости (pip install -r requirements.txt)
  5. Устанавливает сам пакет (pip install -e .)
  6. Запускает GUI
                            ↓
Приложение запущено с изолированным окружением
```

**Преимущества:**
- ✅ Автоматическая установка всего необходимого
- ✅ Изолированное окружение (не загрязняет систему)
- ✅ Проще для пользователей

#### **Способ 3: .exe файл (нет Python требуется)**

```
Вы запускаете:       nAUDIT.exe
                            ↓
PyInstaller:
  • Берет Python интерпретатор
  • Паковывает все зависимости внутри
  • Создает однофайловый исполняемый файл
                            ↓
                     nAUDIT.exe
                            ↓
Преимущества:
  ✅ Один файл
  ✅ Не требует Python
  ✅ Готово распространять
  ✅ Работает на любом Windows
```

## ❓ Почему .exe файла еще нет?

### 📋 Полный процесс создания .exe

```
Этап 1: Разработка кода ✅
  └─ Код написан и готов
  
Этап 2: Установка зависимостей
  └─ Требуется запустить: pip install -r requirements.txt
  
Этап 3: Сборка .exe ← ВЫ СЕЙЧАС ЗДЕСЬ
  └─ Требуется запустить: .\build_exe.ps1
     или: python build_exe.py
     
Этап 4: Результат
  └─ dist/nAUDIT.exe ← готов!
```

### 🛠️ Почему еще нет .exe?

```
Причина: .exe создается ДИНАМИЧЕСКИ при каждой сборке

       Исходные файлы (.py)
              ↓
         build_exe.ps1
            (запуск)
              ↓
         PyInstaller
              ↓
         dist/nAUDIT.exe ← СОЗДАЕТСЯ ВО ВРЕМЯ ВЫПОЛНЕНИЯ
```

**Это нормально!** .exe файл:
- ❌ НЕ хранится в репозитории (слишком большой)
- ✅ Создается когда нужен
- ✅ Собирается из исходного кода автоматически

## 🚀 Пошаговый запуск приложения

### Этап 1: Проверяем, что установлен Python

```powershell
# Откройте PowerShell и выполните:
python --version
```

**Должно вывести:** `Python 3.8` или выше

Если не работает:
- Установите Python с python.org
- Убедитесь, что Python в PATH (опция при установке)

### Этап 2: Переходим в папку проекта

```powershell
cd G:\CODING\nAUDIT
```

### Этап 3: Запускаем скрипт подготовки

**Вариант A: Автоматический (рекомендуется)**

```powershell
# Разрешаем исполнение скриптов
Set-ExecutionPolicy Bypass -Scope Process -Force

# Запускаем скрипт быстрого старта
.\run_naudit.ps1
```

**Вариант B: Ручной (если скрипт не работает)**

```powershell
# 1. Проверяем Python
python --version

# 2. Создаем виртуальное окружение
python -m venv v.naudit

# 3. Активируем его
.\v.naudit\Scripts\Activate.ps1

# 4. Устанавливаем зависимости
pip install --upgrade pip
pip install -r requirements.txt

# 5. Устанавливаем пакет
pip install -e .

# 6. Запускаем GUI
python -m n_audit.gui.main_app
```

### Этап 4: Приложение запустится! 🎉

Вы должны увидеть окно nAUDIT с тремя вкладками.

## 🏗️ Сборка .exe файла (опционально)

**ПОСЛЕ того как GUI работает**, вы можете собрать .exe:

```powershell
# Убедитесь, что виртуальное окружение активировано
.\v.naudit\Scripts\Activate.ps1

# Установите PyInstaller
pip install PyInstaller

# Соберите .exe
.\build_exe.ps1
```

**Результат:**
```
dist/
└── nAUDIT.exe ← готовый исполняемый файл!
```

**Размер:** обычно 100-200 МБ (в зависимости от зависимостей)

### Что происходит при сборке:

```
PyInstaller берет:
  1. Python интерпретатор (40 МБ)
  2. PyQt6 библиотеку (80 МБ)
  3. Все ваши скрипты Python
  4. Все зависимости (pylint, bandit и т.д.)
  
           ↓ ПАКОВЫВАЕТ ВСЕ ВМЕСТЕ ↓
  
  nAUDIT.exe (150+ МБ)
  
  Теперь это ОДИН файл, который можно запустить
  на любом Windows БЕЗ установки Python!
```

## 🔧 Возможные проблемы и их решение

### ❌ Проблема: "Python не найден"

```powershell
python --version
# ↓
# Не найдена команда 'python'

# Решение:
# 1. Установите Python: https://python.org
# 2. При установке выберите "Add Python to PATH"
# 3. Перезагрузитесь
```

### ❌ Проблема: "PyQt6 не установлен"

```powershell
python -m n_audit.gui.main_app
# ↓
# ModuleNotFoundError: No module named 'PyQt6'

# Решение:
pip install PyQt6
```

### ❌ Проблема: "Скрипт не выполняется (PowerShell ошибка)"

```powershell
.\run_naudit.ps1
# ↓
# "File cannot be loaded because running scripts is disabled"

# Решение:
Set-ExecutionPolicy Bypass -Scope Process -Force
.\run_naudit.ps1
```

### ❌ Проблема: "Ошибка при сборке .exe"

```
Решение:
1. Убедитесь, что PyInstaller установлен:
   pip install PyInstaller

2. Проверьте, что GUI работает:
   python -m n_audit.gui.main_app

3. Попробуйте сборку заново:
   python build_exe.py
```
