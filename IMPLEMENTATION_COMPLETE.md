## 🚀 Как начать использовать

### Windows PowerShell
```powershell
# 1. Откройте PowerShell в папке проекта
# 2. Разрешите исполнение скриптов
Set-ExecutionPolicy Bypass -Scope Process -Force

# 3. Быстрый старт (запустит GUI)
.\run_naudit.ps1

# 4. Или соберите .exe файл
.\build_exe.ps1
# Результат: .\dist\nAUDIT.exe
```

### Linux / macOS
```bash
# 1. Откройте терминал
# 2. Сделайте скрипт исполняемым
chmod +x run_naudit.sh

# 3. Быстрый старт
./run_naudit.sh

# 4. Или используйте напрямую
python -m n_audit.gui.main_app
```

### Любая ОС
```bash
# Установка через pip
pip install -r requirements.txt

# Запуск GUI
naudit-gui

# Запуск CLI
naudit --module . --report-level full
```

## 📊 Использование приложения

### Основной workflow
1. **Запустите приложение** (`naudit-gui`)
2. **Выберите проект** (нажмите "Обзор")
3. **Установите параметры** (обычно по умолчанию хорошо)
4. **Нажмите "Начать аудит"** и дождитесь результатов
5. **Просмотрите результаты** на вкладке "Результаты"
6. **Используйте рекомендации** для улучшения кода

### Интерпретация результатов

| Оценка | Действие |
|--------|----------|
| 9-10 | ✅ Отлично, продолжайте |
| 7-8 | ✔️ Хорошо, устраните проблемы |
| 5-6 | ⚠️ Требуется улучшение |
| 3-4 | ❌ Критично, срочно исправляйте |
| 1-2 | 🔴 Критически, переделывайте |

## 🎓 Для разработчиков

### Структура проекта
```
n_audit/
├── gui/              # GUI компоненты
├── audit_manager.py  # Асинхронное управление
├── *_analysis.py     # Модули анализа
└── plugins/          # Расширяемость
```

### Добавление нового анализа
1. Создайте новый модуль в `n_audit/`
2. Реализуйте функцию `run(args, reports_dir)`
3. Зарегистрируйте в `core.py`

### Создание плагина
1. Создайте файл в `n_audit/plugins/`
2. Реализуйте `run_plugin_checks(args, reports_dir)`
3. Плагин загрузится автоматически
