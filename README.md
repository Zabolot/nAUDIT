# nAUDIT 2.1

**Профессиональный инструмент для комплексного анализа качества кода Python проектов**

> ✨ **v2.1:** Добавлена интерактивная граф-визуализация ошибок, улучшенный анализ, работающий экспорт, современный интерфейс

## 🎯 Возможности

- **📊 Статический анализ кода** — проверка синтаксиса, стиля и сложности с radon, pylint, flake8, mypy
- **🔒 Проверка безопасности** — поиск уязвимостей с bandit и safety
- **🧪 Анализ тестов** — оценка покрытия тестами с pytest и coverage
- **🏗️ Проверка инфраструктуры** — анализ Docker, SQL, зависимостей и окружения
- **💡 Интеллектуальные рекомендации** — персонализованные советы по исправлению проблем
- **📈 Подробные отчёты** — HTML и JSON отчёты с детальной информацией
- **🖥️ Современный GUI** — минималистичный интерфейс на PyQt6
- **🌳 Интерактивная визуализация** — два режима просмотра ошибок (дерево и граф) в одной вкладке
- **🕸️ Граф-визуализация** — интерактивная сетевая визуализация всех файлов проекта (Plotly)
- **💾 Экспорт графов** — сохранение интерактивных графиков в HTML для доступа из браузера
- **📦 Готовый .exe файл** — локальная установка без зависимостей

## 📖 Использование

### Графический интерфейс (рекомендуется)

```bash
naudit-gui
```

Интерфейс состоит из 3 вкладок:
1. **Аудит** — выбор проекта и запуск аудита
2. **Результаты** — просмотр оценки и рекомендаций
3. **Справка** — встроенная документация

### Командная строка

```bash
naudit --module /path/to/project --report-level full --export-format html
```

Параметры:
- `--module` — путь к проекту
- `--exclude` — исключить файлы/папки
- `--report-level` — краткий (brief), полный (full) или детальный (detailed)
- `--export-format` — HTML или JSON
- `--verbose` — подробное логирование

## 📊 Интерпретация результатов

### Оценка качества (1-10)

| Оценка | Статус | Действие |
|--------|--------|----------|
| 9-10 | ✅ Отличное | Поддерживайте уровень |
| 7-8 | ✔️ Хорошее | Устраните найденные проблемы |
| 5-6 | ⚠️ Среднее | Требуется улучшение |
| 3-4 | ❌ Низкое | Срочно исправляйте |
| 1-2 | 🔴 Критическое | Переделка проекта |

### Типы проблем

- **Ошибки кода** — критические синтаксические ошибки
- **Проблемы безопасности** — уязвимости, требующие срочного исправления
- **Нарушения стиля** — отклонения от PEP8
- **Высокая сложность** — функции, требующие рефакторинга

### Проблема: "pylint не установлен"

```bash
pip install pylint bandit pytest coverage
```

### Проблема: "Ошибка при запуске GUI"

```bash
pip install --upgrade PyQt6
```

### Проблема: "Аудит очень медленно"

- Это нормально для больших проектов
- Закройте фоновые приложения
- Увеличьте время таймаута в конфигурации

## 📊 Экспорт графов

### Где сохраняются графы?

**Автоматически**:
- Путь: `~/.naudit/reports/graphs/`
- Формат: `graph_YYYYMMDD_HHMMSS.html`
- Создаются при каждом анализе проекта

**Вручную через диалог**:
1. Нажмите кнопку **"📤 Экспорт"**
2. Выберите место сохранения графика
3. Граф сохранится в выбранную папку

### Открытие графа в браузере

```bash
# Windows
start "$env:USERPROFILE\.naudit\reports\graphs\graph_*.html"

# macOS
open ~/.naudit/reports/graphs/graph_*.html

# Linux
xdg-open ~/.naudit/reports/graphs/graph_*.html
```

**Возможности**:
- ✅ Масштабирование (Wheel Mouse)
- ✅ Перетаскивание (Drag)
- ✅ Информация при наведении (Hover)
- ✅ Фокус на узлы (Click)
- ✅ Работает offline (встроенная библиотека Plotly)
