## Что это?

**nAUDIT v4.0** - это профессиональный инструмент для глубокого анализа Python проектов с реальными метриками, интерактивными графиками, умными рекомендациями и красивым GUI.

### ✨ Главные особенности v4

- ✅ **Настоящий анализ** - использует pylint, flake8, mypy, bandit для реального анализа
- ✅ **Обоснованный рейтинг** - от 1 до 10, вычисляется из 4 компонентов (35% качество, 30% безопасность, 20% тесты, 15% структура)
- ✅ **Интерактивное дерево ошибок** - развернуть каждую проблему и посмотреть контекст
- ✅ **Профессиональные отчеты** - HTML, JSON и CSV форматы
- ✅ **Умные рекомендации** - привязаны к конкретным проблемам в коде
- ✅ **5 типов графиков** - pie, bar, radar, gauge и другие
- ✅ **Полный GUI** - 6 вкладок, история, справка, легко использовать
- ✅ **100% тестирование** - 9 из 9 тестов пройдены

## Быстрый старт

### 1. Установка

```bash
# Клонировать репозиторий
git clone https://github.com/yourusername/naudit.git
cd naudit

# Активировать виртуальную среду
.\v.naudit\Scripts\Activate.ps1  # Windows
source v.naudit/bin/activate      # Linux/macOS

# Установить зависимости
pip install -r requirements.txt
```

### 2. Запуск

```bash
# GUI (рекомендуется)
python run_naudit_gui.py

# CLI
python -m n_audit --path /your/project --export
```

### 3. Экспорт

Отчеты сохраняются в `~/.naudit/reports/` в форматах:
- 📊 **HTML** - красивый отчет для браузера
- 📋 **JSON** - структурированные данные
- 📑 **CSV** - таблица для Excel

## FAQ

**Q: Почему рейтинг низкий?**
A: Проверьте вкладку "🌳 Ошибки" - там показаны все проблемы.

**Q: Как исправить ошибки?**
A: В вкладке "💡 Рекомендации" есть примеры кода для исправления.

**Q: Почему некоторые ошибки не найдены?**
A: Установите инструменты анализа: `pip install pylint flake8`

**Q: Можно ли автоматически исправить?**
A: Нет, nAUDIT только находит проблемы. Исправление - на разработчике.
