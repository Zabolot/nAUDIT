## 🎯 Цель сессии

Реализовать интерактивную **граф-визуализацию проекта** как альтернативный режим просмотра ошибок в одной вкладке с иерархическим деревом.

### Требования пользователя

> "Древо графов должно располагаться там же, где и имеющееся иерархическое древо ошибок, в той же вкладке."

**Перевод:** Граф-визуализация должна быть в той же вкладке, что и иерархическое дерево, с возможностью переключения между режимами просмотра.

## 📋 Выполненные задачи

### 1. ✅ Создание GraphVisualizerWidget

**Файл:** `n_audit/gui/graph_visualizer.py` (~400 строк)

**Функциональность:**
- Интерактивная сетевая визуализация на основе pyvis
- Узлы = файлы проекта
- Размер узла = количество строк кода
- Цвет узла = максимальная серьезность ошибок (CRITICAL/HIGH/MEDIUM/LOW)
- Текст на узле = имя файла + счётчик ошибок
- Групповая визуализация по папкам (HSV палитра)
- Рёбра между файлами в одной папке
- Интерактивные элементы управления

**Характеристики:**
- Физика графа для автоматического позиционирования
- Фильтрация по серьезности
- Масштабирование (50-200%)
- Переключение метак и связей
- Кнопка обновления

### 2. ✅ Создание ErrorVisualizationWidget

**Файл:** `n_audit/gui/error_visualization.py` (~150 строк)

**Функциональность:**
- Комбинированный компонент с тремя режимами просмотра:
  - **TREE:** Иерархическое дерево ошибок
  - **GRAPH:** Граф-визуализация проекта
  - **SPLIT:** Оба одновременно (50/50)
- QStackedWidget для быстрого переключения между режимами
- Кнопки управления режимами в панели управления
- Синхронизированная загрузка данных в оба компонента

**API:**
- `populate_from_report(report, project_root)` - заполнение данными
- `clear()` - очистка
- `filter_by_severity(min_severity)` - фильтрация
- `get_current_mode()` - получение текущего режима

## ✨ Особенности реализации

### 1. Три режима просмотра

- **Дерево**: Иерархическая структура (v4.0 функциональность)
- **Граф**: Новая интерактивная визуализация
- **Разделённый**: Лучшее из обоих миров

### 2. Система цветов

```
Зелёный (#44dd44)   = LOW (низкий риск)
Жёлтый (#ffcc00)    = MEDIUM (средний риск)
Оранжевый (#ff9900) = HIGH (высокий риск)
Красный (#ff4444)   = CRITICAL (критический риск)
```

### 3. Интерактивность

- Перемещение узлов мышкой
- Зумирование колесом мыши
- Панировка кликом и перемещением
- Выбор узла для выделения
- Подсказки при наведении

### 4. Производительность

- Кэширование HTML графа
- Ленивая загрузка (граф рендерится только при переключении)
- Ограничение рёбер для больших проектов
- Асинхронный рендеринг через QWebEngineView

## 🚀 Использование

### Запуск приложения

```bash
# Активировать виртуальную среду
v.naudit\Scripts\Activate.ps1

# Запустить приложение
python -m n_audit.gui.main_app
```

### Использование граф-визуализации

1. **Откройте приложение**
2. **Выберите проект и запустите аудит**
3. **Перейдите на вкладку "🌳 Ошибки"**
4. **Выберите режим просмотра:**
   - `🌳 Дерево` - иерархическое дерево
   - `🕸️ Граф` - интерактивный граф
   - `📊 Оба` - оба одновременно

### Управление графом

- **Фильтр**: Выберите минимальную серьезность
- **Масштаб**: Используйте ползунок (50-200%)
- **Метки**: Галочка для показа имён файлов
- **Связи**: Галочка для показа рёбер между файлами
- **Обновить**: Кнопка 🔄 для перерендеринга
