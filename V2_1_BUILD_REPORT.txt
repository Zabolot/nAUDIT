🧪 КАК ПРОТЕСТИРОВАТЬ
====================

1. Запуск приложения:
   - Запустите G:\CODING\nAUDIT\dist\nAUDIT.exe
   - Должно открыться окно без ошибок

2. Выбор проекта:
   - Кнопка "Выбрать папку"
   - Выберите папку с Python проектом

3. Запуск анализа:
   - Кнопка "Начать аудит"
   - Должна показаться 6-фазовый прогресс
   - Не должно быть ошибок в консоли

4. Проверка результатов:
   - Вкладка "Результаты" должна показать:
     * Рейтинг (НЕ 10/10 для реальных проектов)
     * Таблицу статистики
     * ASCII-график распределения
   - НЕ должны быть скрыты результаты анализа

5. Экспорт:
   - Кнопка "Экспорт отчёта"
   - Проверьте папку .audit_results/reports/
   - Должны быть созданы файлы:
     * audit_report_TIMESTAMP.json
     * audit_report_TIMESTAMP.html
   - HTML должен открыться в браузере

6. История:
   - Вкладка "История"
   - Должны быть записи прошлых анализов
   - Можно просмотреть детали
