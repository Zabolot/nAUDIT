## 📁 Где Находятся Графы?

### Временное сохранение (для GUI)
```
{TempDir}/naudit_graph_temp.html
```
- Windows: `C:\Users\<USER>\AppData\Local\Temp\naudit_graph_temp.html`
- Linux: `/tmp/naudit_graph_temp.html`
- Перезаписывается при каждом рендеринге

### Постоянное сохранение (история)
```
~/.naudit/reports/graphs/
```
- Windows: `C:\Users\<USER>\.naudit\reports\graphs\`
- Linux: `/home/<username>/.naudit/reports/graphs/`
- Формат: `graph_YYYYMMDD_HHMMSS.html`
- Метаданные: `graph_YYYYMMDD_HHMMSS_meta.json`

### Пользовательский экспорт
- Сохраняется в выбранную пользователем папку
- По умолчанию - **Desktop**
- Вызывается через кнопку "📤 Экспорт"

## 🚀 Как Использовать?

### Экспорт графа
```
1. Нажмите "📤 Экспорт" в главном окне
2. Выберите место сохранения (по умолчанию Desktop)
3. Граф сохранится
4. Откройте .html файл в браузере
```

### Просмотр в браузере
```bash
# Найти самый свежий граф
ls -1 ~/.naudit/reports/graphs/graph_*.html | sort -r | head -1 | xargs xdg-open

# Или открыть конкретный файл
firefox ~/.naudit/reports/graphs/graph_20240115_143022.html
```

### Возможности в браузере
- ✅ **Wheel Mouse** - масштабирование
- ✅ **Drag** - перемещение
- ✅ **Hover** - информация о файле
- ✅ **Click** - фокус на узел
