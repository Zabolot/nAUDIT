# Руководство: Сохранение и Экспорт Графов Проекта

## 📍 Где сохраняются графы?

### Временный граф (для отображения)
**Путь**: `{TempDir}/naudit_graph_temp.html`

- **Windows**: `C:\Users\<USERNAME>\AppData\Local\Temp\naudit_graph_temp.html`
- **Linux**: `/tmp/naudit_graph_temp.html`
- **macOS**: `/var/folders/.../T/naudit_graph_temp.html`

**Назначение**: Временный файл, который перестраивается при каждом анализе проекта. Используется для отображения графа в GUI.

⚠️ **Важно**: Содержимое перезаписывается при каждом рендеринге графа!

### Автоматически экспортируемые графы
**Путь**: `~/.naudit/reports/graphs/`

- **Windows**: `C:\Users\<USERNAME>\.naudit\reports\graphs\`
- **Linux**: `/home/<username>/.naudit/reports/graphs/`
- **macOS**: `/Users/<username>/.naudit/reports/graphs/`

**Формат**: `graph_YYYYMMDD_HHMMSS.html`

**Назначение**: Постоянное хранилище всех сгенерированных графов с историей анализов

**Содержимое папки**:
```
graphs/
├── graph_20240115_143022.html          # Граф проекта
├── graph_20240115_143022_meta.json     # Метаданные (nodes count, settings)
├── graph_20240115_150531.html
├── graph_20240115_150531_meta.json
└── ...
```

---

## 🚀 Как экспортировать граф?

### Способ 1: Экспорт при сохранении отчета

1. Нажмите кнопку **"📤 Экспорт"** в главном окне
2. Откроется окно "Сохранить файл"
3. **Граф автоматически сохраняется** в:
   - Указанное вами место (dialog)
   - `~/.naudit/reports/graphs/` (всегда)

**Вывод в интерфейсе**:
```
✅ Отчеты успешно сохранены:

📄 JSON: C:\Users\User\.naudit\reports\report_20240115_143022.json
📊 HTML: C:\Users\User\.naudit\reports\report_20240115_143022.html
📋 CSV: C:\Users\User\.naudit\reports\report_20240115_143022.csv
📈 Граф: C:\Users\User\Desktop\naudit_graph_20240115_143022.html
```

### Способ 2: Сохранение в пользовательское место

При вызове `export_current_graph()` появляется dialog сохранения файла:
- Позволяет выбрать папку и имя
- По умолчанию предлагает **Desktop** и имя `naudit_graph_YYYYMMDD_HHMMSS.html`

## 📊 Структура экспортируемого графа

### HTML файл (Interactive Graph)

Каждый `.html` файл содержит:

```html
<!DOCTYPE html>
<html>
<head>
    <!-- Встроенная библиотека Plotly (~3 MB) -->
    <script src='https://cdn.plot.ly/plotly-latest.min.js'></script>
</head>
<body>
    <!-- Интерактивный граф с технологией Plotly -->
    <!-- Можно открыть в любом браузере -->
</body>
</html>
```

**Возможности**:
- ✅ Масштабирование (Wheel Mouse)
- ✅ Перетаскивание (Drag)
- ✅ Зум на отдельные узлы (Click)
- ✅ Информация при наведении (Hover)
- ✅ Работает Offline (встроенный JS)

### JSON Метаданные

Файл `graph_YYYYMMDD_HHMMSS_meta.json`:

```json
{
  "timestamp": "20240115_143022",
  "node_count": 47,
  "file_size_kb": 3087.5,
  "scale_factor": 1.0,
  "show_labels": true,
  "show_edges": true
}
```

## 🔧 Технические детали

### Визуализация

| Параметр | Описание |
|----------|---------|
| **Библиотека** | Plotly 6.4.0 |
| **Формат** | HTML5 с встроенным JS |
| **Размер** | ~3 MB (включает полную библиотеку Plotly) |
| **Совместимость** | Все современные браузеры (Chrome, Firefox, Safari, Edge) |

### Узлы графа

- **Размер узла** = количество ошибок + строк кода
- **Цвет узла** = статус (зелёный/жёлтый/оранжевый/красный)
- **Группировка** = по папкам проекта ("облака")
- **Рёбра** = связи между файлами в одной папке

### Оптимизация

```python
# Почему 3 MB?
include_plotlyjs='inline'  # Встраиваем полную библиотеку для работы offline
# Преимущество: граф работает без интернета
# Недостаток: большой размер файла
```

Даже с параметром `include_plotlyjs='cdn'` QWebEngineView требует локального JS для безопасности.

## 💡 Рекомендации

### Для анализа

1. **Открыть в браузере**: Double-click на `.html` файл
2. **Изучить проект**:
   - Наведитесь на узел → увидите детали файла
   - Кликните на узел → временный зум для фокуса
   - Используйте Wheel Mouse → масштабирование

### Для хранения

- **Автоматически сохраняется** в `~/.naudit/reports/graphs/`
- **Никогда не удаляется** программой
- **Можно использовать** для истории анализов

### Для обмена

- 📧 **Email**: Отправьте `.html` файл как вложение
- 💾 **USB**: Скопируйте файл на флешку
- 🌐 **Web**: Загрузите на хостинг (любой статический сервер)

## 🐛 Troubleshooting

### Граф не отображается в браузере?

1. ✅ Проверьте, что файл `.html` создан
2. ✅ Откройте его в другом браузере
3. ✅ Проверьте размер файла (должен быть >1 MB)
4. ✅ Убедитесь, что путь не содержит специальных символов

### Где найти графы всех анализов?

```
cd ~/.naudit/reports/graphs/
```

Все графы хранятся с временными метками для отслеживания истории.

### Как скопировать граф?

```bash
# Windows PowerShell
Copy-Item "$env:USERPROFILE\.naudit\reports\graphs\graph_*.html" -Destination "D:\backups\"

# Linux/macOS
cp ~/.naudit/reports/graphs/graph_*.html ~/backups/
```
