## 📋 Проблема

**Симптом:** Граф-визуализация не отображается в приложении. Пользователь видит:
- Белый пустой экран вместо графа
- Или прогресс-бар, стоящий на 0%

**Область:** Вкладка "Граф" (Graph Mode) в ErrorVisualizationWidget

---

## 🔍 Анализ Причин

### Основные подозреваемые:

1. **Цвет узлов сливается с фоном** (белый на белом)
   - PyVis использует белый фон по умолчанию
   - Узлы с малым контрастом
   
2. **Размер узлов слишком мал**
   - Узлы могут быть невидимы при большом количестве файлов
   - Масштабирование не учитывает количество ошибок

3. **HTML не загружается правильно**
   - QWebEngineView может не загружать локальные файлы
   - Проблемы с кодировкой UTF-8

4. **Fallback недостаточен**
   - Если PyVis не установлен, граф не отображается
   - Нет альтернативных способов визуализации

---

## ✅ Решение

### 1. Переход на Plotly (Основное решение)

**Преимущества:**
- ✅ Лучший контроль над цветами и стилем
- ✅ Встроенная интерактивность
- ✅ Поддержка темных и светлых фонов
- ✅ Чёткий рендеринг на разных разрешениях
- ✅ Лучшее отображение больших графов

**Изменения в `graph_visualizer.py`:**

```python
# Добавлены импорты
try:
    import plotly.graph_objects as go
    from plotly.offline import plot as plotly_plot
    HAS_PLOTLY = True
except ImportError:
    HAS_PLOTLY = False
```

**Новый метод `_render_with_plotly()`:**
- Использует Spring Layout для распределения узлов
- Раскрашивает узлы по серьёзности ошибок
- Размер узла пропорционален количеству ошибок + строкам кода
- Светлый фон (`#fafafa`) вместо белого
- Чёрные границы узлов для контраста

### 2. Улучшенный Fallback на PyVis

**Изменения в `_render_with_pyvis()`:**
- Фон изменён с белого на светлый (`#fafafa`)
- Более крупные шрифты на узлах
- Оптимизация физики для больших графов

### 3. Canvas/SVG как последняя попытка

**Новый метод `_render_with_canvas()`:**
- Использует встроенный SVG (не требует зависимостей)
- Сетка распределения узлов
- Полностью рабочий fallback

**Порядок попыток:**
```
Plotly (лучший результат) 
    ↓ если нет
PyVis (хороший результат)
    ↓ если нет
Canvas/SVG (минимальный результат)
```

### 4. Улучшение цветовой схемы

| Серьёзность | Цвет | RGB | Описание |
|-------------|------|-----|----------|
| CRITICAL | Красный | #ff4444 | Критические ошибки |
| HIGH | Оранжевый | #ff9900 | Серьёзные ошибки |
| MEDIUM | Жёлтый | #ffcc00 | Средние ошибки |
| LOW | Зелёный | #44dd44 | Низкие ошибки |

**Фоны:**
- Основной: `#fafafa` (светло-серый вместо белого)
- Контрастные границы узлов: чёрные (`#000`)

### 5. Улучшение размера узлов

```python
# Новая формула для размера
size = max(15, min(50, 20 + node.errors_count * 5 + int((node.lines_of_code ** 0.5) / 10)))

# Факторы:
# - Базовый размер: 20
# - За каждую ошибку: +5
# - За строки кода: + sqrt(lines) / 10
# - Минимум: 15, Максимум: 50
```

### 6. Добавлены зависимости

**`build_exe_production.py`:**

## 📝 Технические детали

### PyVis HTML структура (Plotly):
```html
<html>
  <head>
    <script src="plotly.min.js"></script>
  </head>
  <body>
    <div id="graph"></div>
    <script>
      // Данные: nodes, edges
      // Layout: title, colors, sizes
      // Rendering: plotly.newPlot()
    </script>
  </body>
</html>
```

### Размер HTML файла:
- Обычно: 50-150 KB
- Большие графы: до 500 KB
- Сохраняется: `%TEMP%\naudit_graph_temp.html`

### QWebEngineView загрузка:
```python
file_url = QUrl.fromLocalFile(str(html_file.resolve()))
self.web_view.load(file_url)
```

## 🔧 Отладка

### Если граф не отображается:

1. **Проверьте логи приложения:**
   ```
   [GraphVisualizer] Используюсь Plotly для рендеринга 156 узлов
   [GraphVisualizer] Plotly HTML сохранен: C:\...\naudit_graph_temp.html
   ```

2. **Проверьте файл HTML:**
   ```powershell
   $file = "$env:TEMP\naudit_graph_temp.html"
   Get-Item $file | Select Name, Length, LastWriteTime
   ```

3. **Попробуйте открыть HTML в браузере:**
   ```powershell
   Invoke-Item "$env:TEMP\naudit_graph_temp.html"
   ```

4. **Если браузер показывает граф, но приложение нет:**
   - Это проблема QWebEngineView
   - Проверьте PyQt6-WebEngine версию
   - Переустановите: `pip install PyQt6-WebEngine --upgrade`

## 🎓 Уроки и Выводы

### Проблемы кроссплатформенности:
- PyVis не всегда работает в bundled приложениях
- Plotly более надёжен для exe файлов
- SVG/Canvas как backup - никогда не подводит

### Контрастность:
- Светлый фон + тёмные границы = видимость
- Цветовая слепота: используйте форму/размер дополнительно
- Белый на белом = невидимо (даже в 2025 году!)

### Рендеринг в QWebEngineView:
- HTML должен быть полностью автономным (no external CDNs при необходимости)
- JavaScript код должен быть inline
- Data URL или file:// протокол - оба работают
