# 📊 Граф-визуализация в nAUDIT v4.1+

## Обзор

С версии v4.1 приложение nAUDIT поддерживает **интерактивную граф-визуализацию** проекта в дополнение к иерархическому дереву ошибок. Оба режима находятся в одной вкладке "🌳 Ошибки" с возможностью переключения между ними.

## Архитектура

### Компоненты

```
ErrorVisualizationWidget (главный компонент)
├── ErrorTreeWidget (режим дерева)
├── GraphVisualizerWidget (режим графа)
└── Split View (оба одновременно 50/50)
```

### Файлы

| Файл | Назначение | Строк |
|------|-----------|-------|
| `error_visualization.py` | Wrapper компонент с режимами | ~150 |
| `graph_visualizer.py` | Граф-визуализация с pyvis | ~400 |
| `tree_widget.py` | Иерархическое дерево | ~480 |

## Режимы просмотра

### 1️⃣ Дерево (Tree Mode)

- **Вид**: Иерархическое дерево структуры проекта
- **Кнопка**: `🌳 Дерево`
- **Особенности**:
  - 3-панельный интерфейс (папки, файлы, ошибки)
  - Цветовая кодировка по серьезности
  - Интерактивная фильтрация
- **Когда использовать**: Нужна структура проекта и детальный список ошибок

### 2️⃣ Граф (Graph Mode)

- **Вид**: Интерактивная сетевая визуализация
- **Кнопка**: `🕸️ Граф`
- **Особенности**:
  - Узлы = файлы проекта
  - Размер узла = количество строк кода
  - Цвет узла = максимальная серьезность ошибок
  - Текст на узле = имя файла + количество ошибок
  - Групповая визуализация по папкам
  - Интерактивные элементы управления
- **Когда использовать**: Нужен общий обзор проекта и распределение ошибок

### 3️⃣ Разделённый вид (Split Mode)

- **Вид**: Дерево слева (50%), Граф справа (50%)
- **Кнопка**: `📊 Оба`
- **Особенности**:
  - Обе визуализации одновременно
  - Синхронизированные данные
  - Полный контроль над обоими видами
- **Когда использовать**: Нужно видеть оба представления одновременно

## Граф-визуализация - Подробно

### Характеристики узлов

| Характеристика | Значение | Описание |
|---|---|---|
| **Размер** | 20-50px | Пропорционален строкам кода в файле |
| **Цвет** | Красный/Оранжевый/Жёлтый/Зелёный | Зависит от максимальной серьезности ошибок |
| **Метка** | Имя файла + счётчик | `tree_widget.py\n5⚠️` |
| **Подсказка** | HTML информация | Папка, строки, ошибки, серьезность |

### Система цветов

```
🔴 CRITICAL (Критические) → #ff4444 (красный)
🟠 HIGH (Высокие)         → #ff9900 (оранжевый)
🟡 MEDIUM (Средние)       → #ffcc00 (жёлтый)
🟢 LOW (Низкие)           → #44dd44 (зелёный)
```

### Группировка по папкам

- Файлы группируются визуально по папкам
- Каждой папке присваивается уникальный цвет в палитре HSV
- Файлы в одной папке соединены друг с другом рёбрами (если имеют ошибки)

### Управление

#### Панель управления

| Элемент | Назначение |
|---------|-----------|
| Фильтр | Показывать только ошибки определённой серьезности |
| Масштаб (50-200%) | Изменять размер узлов |
| Чекбокс "Метки" | Показывать/скрывать текст на узлах |
| Чекбокс "Связи" | Показывать/скрывать рёбра между файлами |
| Кнопка "🔄" | Обновить граф |

#### Интерактивные возможности (внутри графа)

- **Перемещение**: Перетягивать узлы мышкой
- **Зум**: Колесо мыши для масштабирования
- **Панировка**: Клик и перемещение на пустом месте
- **Наведение**: Подсказка при наведении на узел
- **Нажатие**: Выбор узла (выделение)

## Интеграция с main_window_v4

### До интеграции (v4.0)

```python
# Tab: Ошибки
self.tree_widget = ErrorTreeWidget()
self.tabs.addTab(self.tree_widget, "🌳 Ошибки")
```

### После интеграции (v4.1+)

```python
# Tab: Ошибки (с режимами)
self.tree_widget = ErrorVisualizationWidget()
self.tabs.addTab(self.tree_widget, "🌳 Ошибки")

# Запуск - всё то же самое
self.tree_widget.populate_from_report(report, project_root=self.selected_path)
```

## Методы API

### ErrorVisualizationWidget

```python
# Заполнить данными из отчета
widget.populate_from_report(report, project_root=".")

# Очистить
widget.clear()

# Фильтровать по серьезности
widget.filter_by_severity("HIGH")

# Получить текущий режим
mode = widget.get_current_mode()  # ViewMode.TREE, .GRAPH или .SPLIT
```

### GraphVisualizerWidget

```python
# Заполнить данными из отчета
graph.populate_from_report(report, project_root=".")

# Очистить
graph.clear()

# Получить все файлы
files = graph.get_all_files()

# Фильтровать по серьезности
graph.filter_by_severity("CRITICAL")
```

## Примеры использования

### Пример 1: Базовое использование

```python
from n_audit.gui.error_visualization import ErrorVisualizationWidget

# Создание компонента
viz = ErrorVisualizationWidget()

# Заполнение данными
viz.populate_from_report(audit_report, project_root="/path/to/project")

# Добавление в UI
layout.addWidget(viz)
```

### Пример 2: Переключение режимов

```python
# Программное переключение режимов
viz._on_tree_mode()   # Дерево
viz._on_graph_mode()  # Граф
viz._on_split_mode()  # Оба

# Или через enum
from n_audit.gui.error_visualization import ViewMode
current = viz.get_current_mode()
```

### Пример 3: Фильтрация

```python
# Показать только критические ошибки
viz.filter_by_severity("CRITICAL")

# Показать всё
viz.filter_by_severity("LOW")
```

## Производительность

### Оптимизация

- **Кэширование**: HTML граф кэшируется между обновлениями
- **Ленивая загрузка**: Граф рендерится только при переключении в режим графа
- **Ограничение рёбер**: Для файлов в папке соединяются максимум 3 соседних файла

### Ограничения

| Параметр | Значение | Примечание |
|----------|----------|-----------|
| Максимум узлов | ~1000 | При большем количестве зависит от системы |
| Максимум рёбер | ~3000 | Автоматически ограничиваются |
| Время рендеринга | 1-5 сек | В зависимости от количества узлов |

## Проблемы и решения

### Проблема 1: Граф не отображается

**Решение:**
```python
# Проверить что pyvis установлен
pip install pyvis>=0.3

# Проверить что PyQt6-WebEngine установлен
pip install PyQt6-WebEngine>=6.0
```

### Проблема 2: Граф отображается черным экраном

**Решение:**
```python
# Это может быть из-за медленного рендеринга
# Подождите 2-3 секунды после загрузки отчета
# Нажмите кнопку "🔄" для обновления
```

### Проблема 3: Узлы наслаиваются друг на друга

**Решение:**
```python
# Используйте кнопку физики в pyvis (внизу графа)
# Или нажмите "🔄" для перерендеринга
# Или перемещайте узлы мышкой
```

## Развитие

### Планируемые улучшения

- [ ] Анализ импортов между файлами (рёбра = import)
