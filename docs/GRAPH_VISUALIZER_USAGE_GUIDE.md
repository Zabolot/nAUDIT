## 🎨 Основные возможности

### 1. Переключение между Plotly и PyVis

**Верхняя панель → Рендер:**

```
[Рендер: ▼]
├─ Plotly (интерактивный) ← по умолчанию
└─ PyVis (сетевой)
```

**Когда использовать:**
- **Plotly:** Лучше для интерактивности и красоты (100-500 узлов)
- **PyVis:** Лучше для сетевых графов и физики (10-200 узлов)

### 2. Показать/скрыть имена файлов

**Чекбокс "Показать имена":**

- **Отключено (по умолчанию):** На узлах видны только числа ошибок
  ```
  Пример:  5   12   0   1
  ```

- **Включено:** На узлах видны имена файлов + количество ошибок
  ```
  Пример:  main.py    utils.py
           5          12
  ```

### 3. Показать/скрыть связи между файлами

**Чекбокс "Показать связи":**

- **Включено (по умолчанию):** Видны импорты (серые линии)
  ```
  Пример: main.py ─────── utils.py
          config.py ───┐
                        └─── database.py
  ```

- **Отключено:** Только узлы без линий

### 4. Масштабирование

**Slider "Масштаб":**
- Минимум: 20%
- Максимум: 300%
- По умолчанию: 100%

**Также можно:**
- Колесико мыши (в Plotly)
- Zoom жесты (в браузере)

### 5. Обновление графа

**Кнопка "🔄 Обновить":**
- Пересчитывает граф без перезагрузки
- Полезно если изменились ошибки

## ⚙️ Параметры конфигурации

Находятся в начале файла `n_audit/gui/graph_visualizer.py`:

### Исключаемые папки

```python
EXCLUDE_FOLDERS = {
    '.venv', 'venv', '.env',           # Виртуальные окружения
    '__pycache__',                      # Python кэш
    '.git', '.github',                  # Git
    '.pytest_cache', '.tox',            # Тестирование
    'node_modules', '.npm',             # Node.js
    '.idea', '.vscode', '.sublime',    # IDE
    'build', 'dist', '.build',         # Сборка
    'htmlcov', '.coverage',            # Coverage
    '.mypy_cache', '.dmypy',           # MyPy
    '.DS_Store',                        # macOS
}
```

**Как изменить:**
```python
# Добавить свою папку
EXCLUDE_FOLDERS.add('my_temp_folder')

# Или отредактировать файл напрямую
EXCLUDE_FOLDERS = {'.venv', '__pycache__', ...}  # Добавьте свои
```

### Расстояние между облаками папок

```python
GRID_SPACING = 25.0        # Расстояние между облаками (было 10)
```

**Если изменить:**
- **Больше (30-40):** Облака далеко друг от друга
- **Меньше (15-20):** Облака ближе

### Радиус спирали

```python
CLOUD_RADIUS = 3.0         # Радиус спирали внутри облака
MIN_NODE_DISTANCE = 3.0    # Увеличение за каждый оборот
```

**Если изменить:**
- **Больше:** Узлы больше разъезжаются
- **Меньше:** Узлы плотнее

## 💡 Примеры кода

### Пример 1: Создать и настроить виджет

```python
from n_audit.gui.graph_visualizer import GraphVisualizerWidget
from n_audit.core.audit import AuditReport

# Создать виджет
widget = GraphVisualizerWidget()

# Загрузить граф из отчёта аудита
report = AuditReport(...)  # Результат аудита
widget.populate_from_report(report, project_root="/path/to/project")

# Добавить в UI
layout.addWidget(widget)
```

### Пример 2: Переключение рендера программно

```python
# Переключить на PyVis
widget.render_combo.setCurrentIndex(1)

# Переключить на Plotly
widget.render_combo.setCurrentIndex(0)
```

### Пример 3: Включить все опции

```python
# Показать имена файлов
widget.show_labels.setChecked(True)

# Показать связи между файлами
widget.show_edges.setChecked(True)

# Установить масштаб 150%
widget.scale_slider.setValue(150)

# Пересчитать граф
widget.scale_slider.valueChanged.emit(150)
```

### Пример 4: Получить список файлов

```python
files = widget.get_all_files()
print(f"Всего файлов в графе: {len(files)}")

for file_path in files[:10]:  # Первые 10
    print(f"  {file_path}")
```

### Пример 5: Очистить граф

```python
# Удалить все узлы и рёбра
widget.clear()
```

### Пример 6: Проверить исключение файла

```python
# Проверить, будет ли файл исключен
test_paths = [
    '.venv/lib/module.py',      # True - исключить
    '__pycache__/cache.pyc',    # True - исключить
    'src/main.py',              # False - включить
]

for path in test_paths:
    excluded = widget._is_excluded_path(path)
    print(f"{path}: {'ИСКЛЮЧЕНО' if excluded else 'ВКЛЮЧЕНО'}")
```

### Пример 7: Получить цвет папки

```python
# Получить цвет для папки
color_gui = widget._get_folder_color('n_audit/gui')
color_core = widget._get_folder_color('n_audit/core')
color_models = widget._get_folder_color('n_audit/models')

print(f"GUI: {color_gui}")      # hsl(220, 75%, 55%)
print(f"Core: {color_core}")    # hsl(140, 70%, 50%)
print(f"Models: {color_models}") # hsl(290, 68%, 52%)
```

## 🔧 Решение проблем

### Проблема 1: Граф не загружается

**Симптомы:** Белый экран или "Loading..." навсегда

**Решение:**
1. Проверьте консоль на ошибки: `python -c "from n_audit.gui.graph_visualizer import GraphVisualizerWidget"`
2. Убедитесь, что Plotly установлен: `pip install plotly>=6.0`
3. Перезагрузите приложение

### Проблема 2: Слишком много файлов в графе

**Симптомы:** Граф медленный, видны файлы из .venv

**Решение:**
1. Убедитесь, что исключения работают: проверьте EXCLUDE_FOLDERS
2. Добавьте свои папки в EXCLUDE_FOLDERS
3. Перезагрузите аудит

### Проблема 3: Узлы накладываются

**Симптомы:** Узлы лежат один на другом

**Решение:**
1. Измените CLOUD_RADIUS или MIN_NODE_DISTANCE
2. Попробуйте PyVis вместо Plotly (комбобокс)
3. Уменьшите масштаб (Slider)

### Проблема 4: Слишком медленно

**Симптомы:** Долгая отрисовка, зависание

**Решение:**
1. Переключитесь на PyVis (может быть быстрее)
2. Увеличьте GRID_SPACING (меньше обработки)
3. Выключите связи (CheckBox "Показать связи")

### Проблема 5: Связи не видны

**Симптомы:** Нет линий между узлами

**Решение:**
1. Убедитесь, что CheckBox "Показать связи" включен
2. Графы должны иметь импорты для связей
3. В PyVis некоторые связи могут быть скрыты физикой

## ❓ Часто задаваемые вопросы

### В: Почему на узлах числа вместо имён?
**О:** Это специально! Так граф чище. Если нужны имена, включите CheckBox "Показать имена".

### В: Как добавить свою папку в исключения?
**О:** Отредактируйте `EXCLUDE_FOLDERS` в начале `graph_visualizer.py`:
```python
EXCLUDE_FOLDERS.add('my_folder')
```

### В: Какой рендер лучше?
**О:** Зависит:
- **Plotly:** Красивее, интерактивнее, хорош для 100-500 узлов
- **PyVis:** Лучше для сетевых графов, хорош для 10-200 узлов

### В: Можно ли экспортировать граф?
**О:** Да! На странице графа Plotly есть кнопка "Download plot as png" (правый верхний угол).

### В: Почему облака разнесены так далеко?
**О:** Это специально! GRID_SPACING = 25.0 предотвращает визуальный беспорядок.

### В: Могу ли я изменить цвета?
**О:** Да! Функция `_get_folder_color()` генерирует цвета. Отредактируйте логику HSL.

### В: Что если у меня 10,000+ файлов?
**О:** Сначала файлы фильтруются исключениями (~95% удаляется). Если всё ещё много:
1. Добавьте ещё исключения
2. Попробуйте PyVis с отключённой физикой

### В: Как обновить граф после изменения кода?
**О:** Нажмите кнопку "🔄 Обновить" на верхней панели.
