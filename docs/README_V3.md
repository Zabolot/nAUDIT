# nAUDIT v3 - README

**Status: ✅ PRODUCTION READY**

## 🎯 Что это?

nAUDIT v3 - это инструмент анализа кода Python с:
- ✅ Реальными метриками (не фейками)
- ✅ Интерактивными графиками
- ✅ Историей анализов
- ✅ Полной диагностикой

## 🚀 Быстрый старт

### 1. Запустить .exe (самый простой способ)
```powershell
.\dist\nAUDIT_v3.exe
```

### 2. Запустить из Python
```powershell
.\v.naudit\Scripts\Activate.ps1
python -m n_audit.gui.main_app
```

### 3. Или использовать launcher скрипт
```powershell
.\run_naudit_v3.ps1
```

## 📋 Что анализирует?

**6 фаз анализа:**
1. 🔍 Статический анализ кода (pylint, flake8, mypy)
2. 🔒 Проверка безопасности (bandit, safety)
3. 🧪 Тестовое покрытие (pytest, coverage)
4. 🏗️ Инфраструктура (dependencies, configs, Docker)
5. 💡 Рекомендации (автоматические советы)
6. 📄 Экспорт (JSON + HTML)

## 🎨 Возможности

### Главное окно
- **Выбор папки** для анализа
- **Прогресс-бар** с 6 этапами
- **Запуск/Отмена** кнопки

### Вкладка "Результаты"
- 📊 Рейтинг с визуальным индикатором
- 📈 Интерактивные графики (pie chart, bar chart)
- 📋 Таблица найденных проблем (первые 50)
- 💬 Рекомендации по улучшению
- 💾 Кнопка экспорта

### Вкладка "История"
- 📜 Список всех проведённых анализов
- 🔄 Быстрый просмотр результатов
- 📊 Сравнение метрик

### Вкладка "Логи"
- 🔎 Полная диагностика процесса
- 🐛 Видны все ошибки и предупреждения
- 📝 Помощь при отладке

## 🎓 Примеры использования

### Из Python
```python
from n_audit.audit_manager_v2 import AuditManager

manager = AuditManager()

def handle_result(result):
    print(f"Рейтинг: {result.rating}/10")
    print(f"Ошибок: {result.total_issues}")

manager.on_result = handle_result
manager.start_audit("/path/to/project")

import time
time.sleep(10)  # Ждём результата
```

### Из командной строки
```bash
# Просто запустить
.\dist\nAUDIT_v3.exe

# Запустить с PowerShell
.\run_naudit_v3.ps1

# Запустить с batch файлом
.\run_naudit_v3.bat
```
