## 🐛 Если что-то не работает

Запустите .exe с логированием:

```powershell
cd G:\CODING\nAUDIT
.\dist\nAUDIT.exe 2>&1 | Tee-Object -FilePath debug_log.txt
```

И отправьте файл `debug_log.txt` для анализа.
