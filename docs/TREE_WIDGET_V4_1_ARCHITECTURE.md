# 🌳 nAUDIT v4.1 - Новая архитектура дерева ошибок

## Что изменилось

Полностью переделано интерактивное дерево ошибок для более удобного просмотра.

### Старая архитектура (v4.0)
- Группировка: По типам ошибок (ERROR, WARNING, SECURITY, STYLE)
- Проблема: Все ошибки скрыты в иерархии категорий
- Результат: Дерево выглядит пусто/не информативно

### Новая архитектура (v4.1)
✅ **Трёхпанельный интерфейс:**
1. **Левая панель (дерево)**: Структура всех файлов проекта
2. **Средняя панель (список)**: Ошибки в выбранном файле
3. **Правая панель (детали)**: Полная информация об ошибке

## Выделение файлов

**Цветная кодировка по серьезности:**
- 🔴 **#ffe0e0** (светлокрасный) - CRITICAL ошибки
- 🟠 **#ffe8cc** (светлооранжевый) - HIGH ошибки
- 🟡 **#fffacc** (светложёлтый) - MEDIUM ошибки
- 🟢 **#e8ffe8** (светлозелёный) - LOW ошибки

**Файлы с ошибками:**
- Выделены полужирным шрифтом
- Окрашены в соответствующий цвет
- Показано количество ошибок: `📄 file.py (5)`

## Интерактивность

### 1. Выбор файла в дереве
- Автоматически обновляется список ошибок в средней панели
- Показываются только ошибки этого файла
- Ошибки отсортированы по номеру строки

### 2. Выбор ошибки в списке
- Отображается полная информация об ошибке
- Показывается контекст кода (если доступен)
- Выделяется тип ошибки иконкой

### 3. Детали ошибки в правой панели
```
[E501] Line too long (140 > 120)

🔴 CRITICAL · flake8

📁 Файл: src/models/user.py
📍 Позиция: строка 10, столбец 121
🏷️ Код: E501
📋 Тип: style_issue

Описание:
Line too long (140 > 120 characters)

Контекст кода:
    this_is_a_very_long_line_that_exceeds_the_maximum...
```

## Структура файлов

**Путь:** `n_audit/gui/tree_widget.py`

**Главный класс:** `ErrorTreeWidget`

**Связанные классы:**
```python
@dataclass
class CodeIssueInfo:
    """Информация об ошибке"""
    file_path: str
    line_number: int
    column: int
    code: str
    message: str
    severity: str          # CRITICAL, HIGH, MEDIUM, LOW
    issue_type: str        # error, warning, style_issue, security
    context: str
    tool: str
```

## Методы

### Основные
- `populate_from_report(report, project_root)` - Заполнить дерево из отчета
- `clear()` - Очистить всё

### Внутренние
- `_build_file_tree()` - Построить иерархию файлов
- `_on_tree_item_selected()` - Обработка выбора файла
- `_on_issue_selected()` - Обработка выбора ошибки
- `_show_issue_details(issue)` - Показать детали
- `_color_file_item(item, file_path, issues_count)` - Выделить файл
- `_get_max_severity(issues)` - Определить max серьезность

### Утилиты
- `_get_severity_icon(severity)` - Иконка по серьезности
- `_get_color_hex(severity)` - HEX цвет по серьезности
- `_get_folder_font()` - Шрифт для папок

## Пример использования

```python
from n_audit.gui.tree_widget import ErrorTreeWidget
from n_audit.audit_engine import AuditEngine

# Создаём отчет
engine = AuditEngine()
report = engine.audit("./my_project")

# Создаём виджет дерева
tree = ErrorTreeWidget()
tree.populate_from_report(report, project_root="./my_project")

# Слушаем события
tree.issue_selected.connect(lambda issue: print(f"Выбрана ошибка: {issue.code}"))
```

## Фильтрация

```python
# Показать только HIGH и выше по серьезности
tree.filter_by_severity("HIGH")

# Получить все ошибки
all_issues = tree.get_all_issues()
```
