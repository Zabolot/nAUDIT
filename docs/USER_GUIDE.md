## Введение

**nAUDIT** — это профессиональный инструмент для комплексного анализа качества кода Python проектов. Приложение проводит глубокий аудит вашего проекта и предоставляет подробные рекомендации по улучшению.

### Возможности

- **Статический анализ кода** — проверка синтаксиса, стиля и сложности с использованием pylint, radon, flake8, mypy
- **Проверка безопасности** — поиск уязвимостей с помощью bandit и safety
- **Анализ тестов** — оценка покрытия тестами с pytest и coverage
- **Проверка инфраструктуры** — анализ конфигурации, Docker, SQL и окружения
- **Интеллектуальные рекомендации** — персонализированные советы по исправлению проблем
- **Подробные отчёты** — HTML и JSON отчёты с детальной информацией

## Установка

### Вариант 1: Использование готового .exe файла (рекомендуется для Windows)

1. Скачайте файл `nAUDIT.exe`
2. Скопируйте его в удобную папку (например, `C:\Program Files\nAUDIT\`)
3. Создайте ярлык на рабочем столе
4. Запустите приложение двойным щелчком

### Вариант 2: Установка из исходников

#### Требования
- Python 3.8 или выше
- Git (опционально)

#### Процесс установки на Windows

1. **Скачайте исходный код** (или клонируйте репозиторий):
   ```powershell
   git clone <url-проекта>
   cd nAUDIT
   ```

2. **Откройте PowerShell** в папке проекта

3. **Запустите скрипт установки и сборки**:
   ```powershell
   Set-ExecutionPolicy Bypass -Scope Process -Force
   .\build_exe.ps1
   ```

4. **Скрипт автоматически**:
   - Создаст виртуальное окружение
   - Установит все зависимости
   - Соберёт .exe файл

5. **Запустите приложение**:
   ```powershell
   .\dist\nAUDIT.exe
   ```

## Использование GUI приложения

### Интерфейс приложения

nAUDIT имеет интуитивный интерфейс с тремя основными вкладками:

#### Вкладка "Аудит"

Эта вкладка предназначена для запуска аудита вашего проекта.

**Шаг за шагом**:

1. **Выбор проекта**
   - Нажмите кнопку "Обзор"
   - Выберите папку с вашим Python проектом
   - Путь отобразится в поле "Путь к проекту"

2. **Параметры аудита**
   - **Уровень отчёта**:
     - `Краткий (brief)` — быстрый анализ, только основные метрики
     - `Полный (full)` — стандартный анализ (рекомендуется)
     - `Детальный (detailed)` — глубокий анализ со всеми деталями
   
   - **Формат отчёта**:
     - `HTML` — красивый интерактивный отчёт (рекомендуется)
     - `JSON` — структурированный формат для интеграции

3. **Запуск аудита**
   - Нажмите кнопку "Начать аудит"
   - Следите за прогрессом на визуальной полоске
   - Смотрите лог аудита внизу

4. **Отмена аудита**
   - Нажмите кнопку "Отмена" если нужно остановить процесс
   - Текущие результаты будут сохранены

#### Вкладка "Результаты"

Результаты появляются здесь после завершения аудита.

**Компоненты**:

- **Оценка качества** (0-10)
  - Визуальная оценка в центре
  - Описание справа (Отличное/Хорошее/Среднее/Низкое/Критическое)

- **Статистика**
  - Количество найденных проблем
  - Разбивка по типам (код, безопасность)
  - Оценка за каждую категорию

- **Рекомендации**
  - Конкретные советы по улучшению
  - Приоритизированный список действий

- **Экспорт отчёта**
  - Кнопка для сохранения подробного отчёта

#### Вкладка "Справка"

Встроенная справка с часто задаваемыми вопросами и рекомендациями.

### Пример использования

```
1. Запустите nAUDIT.exe
   ↓
2. Нажмите "Обзор" и выберите папку проекта: C:\Users\Developer\MyProject
   ↓
3. Оставьте параметры по умолчанию (Полный отчёт, HTML)
   ↓
4. Нажмите "Начать аудит"
   ↓
5. Дождитесь завершения (может занять 1-5 минут в зависимости от размера проекта)
   ↓
6. Просмотрите результаты на вкладке "Результаты"
   ↓
7. Воспользуйтесь рекомендациями для улучшения кода
```

## Интерпретация результатов

### Оценка качества (Rating)

nAUDIT выставляет оценку от 1 до 10:

| Оценка | Описание | Действие |
|--------|---------|----------|
| 9-10 | Отличное качество кода | Поддерживайте текущий уровень |
| 7-8 | Хорошее качество кода | Рекомендуется устранить найденные проблемы |
| 5-6 | Среднее качество кода | Требуется работа над улучшением |
| 3-4 | Низкое качество кода | Срочно требуются исправления |
| 1-2 | Критическое качество кода | Проект нуждается в срочном переделе |

### Типы проблем

#### Проблемы кода (pylint, flake8)
- **Ошибки (E)**: Синтаксические ошибки, критические проблемы
- **Предупреждения (W)**: Потенциальные проблемы, которые не всегда критичны
- **Нарушения стиля (C)**: Отклонения от стандарта PEP8

#### Проблемы безопасности (bandit)
- **ВЫСОКИЙ приоритет**: Серьёзные уязвимости, могут привести к взлому
- **СРЕДНИЙ приоритет**: Потенциальные проблемы безопасности
- **НИЗКИЙ приоритет**: Рекомендации по лучшей практике

#### Сложность кода (radon)
- Цикломатическая сложность > 8: Функция слишком сложна, требуется рефакторинг
- Длина функции > 50 строк: Рассмотрите разделение функции

#### Покрытие тестами (coverage)
- \>= 80%: Хорошее покрытие
- 60-79%: Недостаточное покрытие
- < 60%: Критически низкое покрытие

### Рекомендации

После каждого аудита приложение предлагает список рекомендаций. Они приоритизированы:

1. **Критические рекомендации** — срочные проблемы безопасности или ошибки
2. **Важные рекомендации** — проблемы качества, которые нужно решить
3. **Рекомендуемые рекомендации** — улучшения для повышения качества

## Часто задаваемые вопросы

### В: Сколько времени занимает аудит?

О: Время зависит от размера проекта:
- Маленький проект (< 100 файлов): 30 сек - 1 мин
- Средний проект (100-1000 файлов): 1-3 мин
- Большой проект (> 1000 файлов): 3-10 мин

### В: Где сохраняются результаты?

О: Результаты сохраняются в папке `.audit_results` вашего проекта:
```
MyProject/
├── .audit_results/
│   ├── reports/
│   │   ├── full_report.html  ← Основной отчёт
│   │   ├── pylint_full.json
│   │   ├── security_issues.json
│   │   └── ...
│   └── configs/
│       ├── requirements_snapshot.txt
│       └── ...
└── ...
```

### В: Могу ли я запустить аудит через командную строку?

О: Да! Используйте команду:
```bash
naudit-gui
```

Или напрямую через Python:
```bash
python -m n_audit.gui.main_app
```

### В: Какие зависимости нужны для работы?

О: Основные зависимости:
- PyQt6 (для графического интерфейса)
- pylint (статический анализ)
- bandit (проверка безопасности)
- pytest, coverage (тесты)
- radon (анализ сложности)

Все устанавливаются автоматически при установке.

### В: Может ли nAUDIT анализировать чужие проекты?

О: Да! Просто выберите нужную папку при запуске. nAUDIT анализирует любые Python проекты.

## Поиск и устранение проблем

### Проблема: "Ошибка: Папка не найдена"

**Решение**:
1. Убедитесь, что путь введён правильно
2. Используйте кнопку "Обзор" для выбора папки
3. Не используйте кавычки в пути

### Проблема: "pylint/bandit не установлены"

**Решение**:
```bash
pip install pylint bandit
```

Или переустановите весь пакет:
```bash
pip install --upgrade nAUDIT
```

### Проблема: "Аудит очень долго выполняется"

**Решение**:
1. Это нормально для больших проектов (> 1000 файлов)
2. Убедитесь, что компьютер не работает на полную мощность
3. Закройте ненужные приложения

### Проблема: "Нет результатов / Отчёты пустые"

**Решение**:
1. Проверьте, что это Python проект с .py файлами
2. Убедитесь, что в проекте есть права для чтения
3. Попробуйте запустить aудит от администратора

### Проблема: "AttributeError при запуске"

**Решение**:
1. Переустановите PyQt6:
   ```bash
   pip install --upgrade PyQt6
   ```
2. Проверьте версию Python (требуется 3.8+):
   ```bash
   python --version
   ```

### Проблема: "Файл nAUDIT.exe повреждён"

**Решение**:
1. Загрузите свежую копию приложения
2. Попробуйте переустановить из исходников
3. Отключите антивирус (он может блокировать установку)
