# nAUDIT v4.0 - Полное руководство пользователя

## Что такое nAUDIT?

**nAUDIT v4.0** - это профессиональный инструмент для глубокого анализа Python проектов. Программа проверяет качество кода, безопасность, тестирование, структуру проекта и документацию, выдавая обоснованный рейтинг от 1 до 10.

**Ключевые преимущества v4:**
- ✅ **Настоящий анализ** - не фейк, реальные данные на основе многих инструментов
- ✅ **Интерактивное дерево ошибок** - можно развернуть каждую проблему и посмотреть контекст
- ✅ **Профессиональные отчеты** - HTML, JSON и CSV форматы с красивым дизайном
- ✅ **Умные рекомендации** - конкретные советы по улучшению на основе найденных проблем
- ✅ **Графики и визуализация** - интерактивные диаграммы всех метрик
- ✅ **Справка в программе** - полная информация о том как использовать

## Установка

### 1. Требования
- Python 3.10+
- Windows/macOS/Linux

### 2. Установить зависимости

```bash
# Активировать виртуальную среду (если нужна)
.\v.naudit\Scripts\Activate.ps1  # Windows PowerShell
source v.naudit/bin/activate      # Linux/macOS

# Установить требуемые пакеты
pip install -r requirements.txt
```

### 3. Требуемые инструменты анализа

nAUDIT автоматически обнаружит и использует:
- **pylint** - проверка кода
- **flake8** - стиль кода
- **mypy** - проверка типов
- **bandit** - анализ безопасности
- **pytest** - запуск тестов и покрытие

Их установка опциональна (nAUDIT работает и без них с базовым анализом).

```bash
pip install pylint flake8 mypy bandit coverage pytest
```

## Использование

### Вариант 1: Графический интерфейс (рекомендуется)

```bash
# Запустить GUI
python run_naudit_gui.py

# Или через модуль
python -m n_audit --gui
```

**В GUI:**
1. Нажмите "📁 Выбрать папку"
2. Выберите папку с Python проектом
3. Нажмите "🔬 Запустить аудит"
4. Смотрите результаты во вкладках:
   - **📊 Результаты** - основной рейтинг и метрики
   - **🌳 Ошибки** - интерактивное дерево всех найденных проблем
   - **📈 Графики** - красивая визуализация метрик
   - **💡 Рекомендации** - специфичные советы по улучшению
   - **📜 История** - все сохраненные отчеты
   - **ℹ️ О программе** - справка и информация

### Вариант 2: Командная строка

```bash
# Базовый аудит
python -m n_audit --path /path/to/project

# С экспортом отчетов
python -m n_audit --path /path/to/project --export

# JSON вывод
python -m n_audit --path /path/to/project --json

# Подробное логирование
python -m n_audit --path /path/to/project --verbose
```

### Компоненты оценки

**1. Качество кода (35%)**
- Стиль кода (PEP 8)
- Сложность функций
- Количество ошибок

**2. Безопасность (30%)**
- Hardcoded пароли
- Опасные функции (eval, exec)
- SQL injection vulnerabilities
- Уязвимы компоненты

**3. Тестирование (20%)**
- Наличие test файлов
- Покрытие тестами (%)
- Quantity of tests

**4. Структура проекта (15%)**
- README.md
- setup.py или pyproject.toml
- requirements.txt
- .git репозиторий
- Лицензия
- CI/CD конфиг

## Дерево ошибок (интерактивное)

В вкладке "🌳 Ошибки" вы видите иерархическое дерево всех проблем:

```
🔴 Ошибки (5)
  📄 main.py (3)
    🔴 Строка 42: E501 - Line too long
    🟠 Строка 51: W291 - Trailing whitespace
  📄 utils.py (2)
    🔴 Строка 10: F821 - Undefined name
    🟠 Строка 25: W293 - Blank line contains whitespace

🟠 Предупреждения (12)
  ...

⚠️ Безопасность (2)
  ...
```

**Как использовать:**
- **Развернуть/свернуть** - кликните на стрелку
- **Выбрать ошибку** - кликните на ошибку, справа появятся детали
- **Код ошибки** - стандартные коды (E501, W291 и т.д.)
- **Контекст** - показывает строку кода где ошибка

## Рекомендации

nAUDIT автоматически генерирует рекомендации на основе РЕАЛЬНЫХ проблем найденных в вашем коде:

**Примеры рекомендаций:**
- 🔴 "Добавить тесты" - если test files не найдены
- 🔴 "Исправить проблемы безопасности" - если найдены security issues
- 🟠 "Создать README.md" - если отсутствует
- 🟡 "Улучшить стиль кода" - если много style issues

Каждая рекомендация включает:
- Описание проблемы
- Решение
- Пример кода
- Влияние на рейтинг

## Экспорт отчетов

### Форматы

nAUDIT может сохранить отчет в 3 форматах:

**1. HTML** - красивый отчет для просмотра в браузере
- Включает графики
- Профессиональный дизайн
- Легко делиться

**2. JSON** - структурированные данные
- Для программного использования
- Легко парсить
- Хранит все метрики

**3. CSV** - таблица всех ошибок
- Для Excel / Google Sheets
- Удобно для анализа
- Легко сортировать

### Где сохраняются отчеты?

По умолчанию: `~/.naudit/reports/`

Все отчеты видны во вкладке "📜 История"

## Графики и визуализация

В вкладке "📈 Графики" можно выбрать разные виды визуализации:

- **Общее состояние** - 4 графика: рейтинг, метрики, серьезность, структура
- **Оценка по компонентам** - радарная диаграмма
- **Распределение ошибок** - по инструментам анализа
- **Проблемы по типам** - pie chart
- **Top файлы с проблемами** - bar chart

Все графики интерактивные (можно наводить, увеличивать).

## Часто задаваемые вопросы

### Q: Почему рейтинг низкий?
A: Проверьте вкладку "🌳 Ошибки" и "💡 Рекомендации". nAUDIT показывает конкретные проблемы которые нужно исправить.

### Q: Почему нет графиков?
A: Убедитесь что установлена matplotlib: `pip install matplotlib`

### Q: Как исправить ошибки?
A: Для каждой ошибки в дереве показана строка и описание. В рекомендациях есть примеры кода.

### Q: Почему некоторые ошибки не найдены?
A: Требуются инструменты анализа. Установите pylint/flake8: `pip install pylint flake8`

### Q: Можно ли автоматически исправить ошибки?
A: Нет, nAUDIT только находит проблемы. Исправление - ответственность разработчика.

### Q: Как интегрировать с CI/CD?
A: Используйте CLI режим:
```bash
python -m n_audit --path . --json > audit_result.json
```

## Примеры использования

### Проверить текущий проект
```bash
python -m n_audit --path .
```

### Экспортировать отчет для клиента
```bash
python -m n_audit --path /client/project --export
# Отправить HTML файл из ~/.naudit/reports/
```

### Интеграция в pre-commit hook
```bash
#!/bin/bash
python -m n_audit --path . --json > /dev/null
if [ $? -ne 0 ]; then
    echo "Code audit failed"
    exit 1
fi
```

### Мониторинг качества кода
```bash
# Запустить еженедельно и сравнить рейтинги
python -m n_audit --path . --export
# Сравнить отчеты из разных недель
```
