# 📖 РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ nAUDIT v4.1

## БЫСТРЫЙ СТАРТ ЗА 5 МИНУТ

### 1. Запуск программы
```bash
# Windows
nAUDIT.exe

# Linux/macOS
python run_naudit_gui.py
```

### 2. Выберите папку проекта
- Нажмите кнопку **📁 Выбрать папку**
- Выберите папку с вашим Python кодом
- Нажмите **OK**

### 3. Запустите аудит
- Нажмите **🔬 Запустить аудит**
- Ждите завершения (время зависит от размера проекта)
- После завершения автоматически откроются результаты

### 4. Посмотрите результаты
- **📊 Результаты** - общий рейтинг и метрики
- **🌳 Ошибки** - интерактивное дерево ошибок (новое в v4.1!)
- **📈 Графики** - визуализация результатов
- **💡 Рекомендации** - конкретные советы
- **📜 История** - список всех отчётов
- **ℹ️ О программе** - справка

## 🌳 НОВОЕ В v4.1: ИНТЕРАКТИВНОЕ ДЕРЕВО ОШИБОК

### Структура интерфейса

```
┌─────────────────────────────────────────────────────────────┐
│ nAUDIT v4.1 - Вкладка "🌳 Ошибки"                          │
├─────────────────────────────────────────────────────────────┤
│                                                               │
│  ЛЕВАЯ ПАНЕЛЬ         │  СРЕДНЯЯ ПАНЕЛЬ  │ ПРАВАЯ ПАНЕЛЬ    │
│  (Структура          │  (Ошибки в       │ (Детали          │
│   проекта)           │   файле)         │  ошибки)         │
│                      │                  │                  │
│  📁 n_audit          │                  │                  │
│  ├─ 📄 audit_e...    │  🔴 Line 123:    │ [E501]           │
│  ├─ 📄 report_g...   │     E501 - Line  │ Line too long    │
│  ├─ 📁 gui          │     too long      │ (127 > 120)      │
│  │  ├─ 📄 tree_w...  │  🔴 Line 145:    │                  │
│  │  └─ 📄 main_w...  │     E501 - ...   │ Файл:            │
│  └─ 📁 tests         │                  │ .\n_audit\gui\   │
│                      │                  │ tree_widget.py   │
│                      │                  │                  │
│ 🟢 LOW   (2558)      │                  │ Строка: 127      │
│ 🟡 MEDIUM (0)        │                  │ Колонка: 122     │
│ 🟠 HIGH   (0)        │                  │                  │
│ 🔴 CRITICAL (0)      │                  │ Тип: E501        │
│                      │                  │ Категория:       │
└─────────────────────────────────────────────────────────────┘
```

### Как использовать новое дерево

#### Шаг 1: Просмотр структуры проекта
- **Левая панель** показывает все файлы вашего проекта
- 📁 **Папки** - серым цветом и в курсиве
- 📄 **Файлы** - цветные в зависимости от серьезности ошибок:
  - 🔴 **Красный** - критические ошибки (CRITICAL)
  - 🟠 **Оранжевый** - высокие ошибки (HIGH)
  - 🟡 **Жёлтый** - средние ошибки (MEDIUM)
  - 🟢 **Зелёный** - низкие ошибки/предупреждения (LOW)

#### Шаг 2: Выберите файл
- **Кликните** на файл в левой панели
- В скобках видите количество ошибок в файле
- Например: `📄 tree_widget.py (7)` = 7 ошибок в файле

#### Шаг 3: Посмотрите ошибки в файле
- **Средняя панель** заполнится ошибками выбранного файла
- Ошибки отсортированы по номеру строки (от меньших к большим)
- Каждая строка показывает:
  - 🔴/🟠/🟡/🟢 Иконка серьезности
  - **Line 123** - номер строки
  - **[E501]** - код ошибки
  - **Line too long** - краткое описание

#### Шаг 4: Увидьте детали ошибки
- **Кликните** на ошибку в средней панели
- **Правая панель** покажет полную информацию:
  - **[E501]** - код ошибки
  - **Line too long (127 > 120)** - полное сообщение
  - **Файл:** путь к файлу
  - **Строка:** номер строки
  - **Колонка:** позиция в строке
  - **Тип:** категория ошибки
  - **Инструмент:** какой инструмент её нашёл (flake8, pylint и т.д.)

### Примеры интерпретации ошибок

#### E501 - Line too long (STYLE/LOW)
```python
# ❌ Плохо: строка более 120 символов
very_long_function_name(parameter1, parameter2, parameter3, parameter4, parameter5)

# ✅ Хорошо: разбить на несколько строк
very_long_function_name(
    parameter1, parameter2, parameter3, 
    parameter4, parameter5
)
```

#### W291 - Trailing whitespace (STYLE/LOW)
```python
# ❌ Плохо: пробелы в конце строки
message = "Hello world"    # <- пробелы здесь

# ✅ Хорошо: удалить пробелы
message = "Hello world"
```

## 📊 ИНТЕРПРЕТАЦИЯ МЕТРИК

### Рейтинг (0-10)
- 🔴 **1.0-3.0** - Плохое состояние, срочные правки
- 🟠 **3.0-5.0** - Есть проблемы, требует внимания
- 🟡 **5.0-7.0** - Среднее состояние, есть чему улучшаться
- 🟢 **7.0-10.0** - Хорошее состояние, качественный код

### Типы ошибок

| Значение | Иконка | Описание | Примеры |
|----------|--------|---------|---------|
| CRITICAL | 🔴 | Критические проблемы | Security issues, syntax errors |
| HIGH | 🟠 | Серьёзные проблемы | Complex functions, missing tests |
| MEDIUM | 🟡 | Средние проблемы | Code style, warnings |
| LOW | 🟢 | Небольшие улучшения | Formatting, comments |

### Компоненты оценки
- **Качество кода** - pylint, flake8 результаты
- **Безопасность** - bandit результаты
- **Тестирование** - coverage результаты
- **Структура** - наличие README, setup.py, Git, CI/CD

## 🐛 解决 ПРОБЛЕМ

### Проблема: Программа медленно загружает файлы
**Решение:** 
- Это нормально для больших проектов (10000+ ошибок)
- Ждите 1-2 минуты на загрузку
- Можно уменьшить область сканирования в настройках

### Проблема: Нет результатов после аудита
**Решение:**
- Убедитесь что выбрана правильная папка
- В папке должны быть .py файлы
- Попробуйте нажать F5 для обновления
- Посмотрите в консоли есть ли ошибки (если запускали из консоли)

### Проблема: Ошибка при экспорте
**Решение:**
- Проверьте что папка не защищена
- Попробуйте другое место для сохранения
- Убедитесь что диск не переполнен
