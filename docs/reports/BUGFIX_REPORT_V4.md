# Отчет об исправлении ошибок v4.0 - 13.11.2025

## Проблема 1: AttributeError в tree_widget.py
**Статус:** ✅ ИСПРАВЛЕНО

**Симптомы:**
- .exe вылетает при нажатии кнопки "Запустить аудит"
- Ошибка: `'MetricsSnapshot' object has no attribute 'is_empty'`
- Строка: `n_audit/gui/tree_widget.py:103`

**Причина:**
- Использован неправильный путь к атрибуту
- Атрибут `is_empty` находится в `AuditReport`, а не в `MetricsSnapshot`

**Решение:**
```python
# ДО (неправильно)
if report.metrics.is_empty:

# ПОСЛЕ (правильно)
if report.is_empty:
```

**Файл:** `n_audit/gui/tree_widget.py`, строка 104

## Проблема 2: AttributeError в metrics_visualizer.py
**Статус:** ✅ ИСПРАВЛЕНО

**Симптомы:**
- .exe вылетает при отрисовке графиков
- Ошибка: `'MetricsSnapshot' object has no attribute 'is_empty'`
- Строка: `n_audit/gui/metrics_visualizer.py:79`

**Причина:**
- Та же проблема как в tree_widget.py
- Неправильный путь к атрибуту

**Решение:**
```python
# ДО (неправильно)
if self.report.metrics.is_empty:

# ПОСЛЕ (правильно)
if self.report.is_empty:
```

**Файл:** `n_audit/gui/metrics_visualizer.py`, строка 79

## Проблема 3: UnicodeEncodeError в Windows консоли
**Статус:** ℹ️ ИНФОРМАЦИЯ

**Симптомы:**
- При сборке .exe на Windows CP1251 кодировке возникают ошибки с emoji
- Ошибка: `UnicodeEncodeError: 'charmap' codec can't encode character`

**Причина:**
- Windows PowerShell и консоль используют CP1251 кодировку
- Emoji требуют UTF-8

**Решение:**
- В скрипте `build_exe_v4.py` заменены emoji на ASCII текст в print statements
- В GUI коде emoji допустимы (PyQt6 поддерживает UTF-8)

**Файл:** `build_exe_v4.py`

---

## Проблема 4: Размер .exe слишком большой
**Статус:** ⚠️ НОРМАЛЬНО

**Симптомы:**
- nAUDIT_v4.exe = 131.19 MB (нельзя назвать "меньше")

**Причина:**
- PyQt6 включает все Qt6 библиотеки (~40 MB)
- matplotlib включает все бэкенды и данные (~30 MB)
- Python runtime (~20 MB)

**Действие:**
- Размер нормальный для приложения на PyQt6
- v3 был примерно такого же размера (130.36 MB)
- Различия в рамках погрешности (~1 MB)
