## 📞 ПОДДЕРЖКА

**Основные команды:**

```powershell

python build_exe_fast.py

# Сборка полная версия
python build_exe_v2_1.py

# Проверка результата

# Запуск приложения
& "dist\nAUDIT.exe"

# Размер файла
(Get-Item dist\nAUDIT.exe).Length / 1MB
```

**Частые проблемы:**

| Проблема | Решение |
|----------|---------|
| PyInstaller не найден | `pip install PyInstaller --upgrade` |
| Долгая сборка | Используйте `build_exe_fast.py` |
| Недостаточно памяти | Закройте приложения, перезагрузитесь |
| Диск полный | Удалите `build/` папку перед сборкой |
