# Новый билдер для nAUDIT v2.1.0

## 📝 Описание

Создана улучшенная версия билдера на основе `build_exe_v4.py` с поддержкой всех компонентов v2.1.0:
- Иерархическое древо ошибок
- Граф визуализация  
- Интерактивные режимы просмотра (TREE/GRAPH/SPLIT)

## 🎯 Созданные файлы

### 1. `build_exe_v2_1.py` - Полная версия
**Назначение:** Полная сборка с максимальной компатибильностью  
**Файлы импортов:** 45 скрытых импортов  
**Параметры:** Полный набор конфигураций  
**Время сборки:** ~3-5 минут  

**Использование:**
```powershell
cd g:\CODING\nAUDIT
v.naudit\Scripts\python build_exe_v2_1.py
```

### 2. `build_exe_fast.py` - Оптимизированная версия (РЕКОМЕНДУЕТСЯ)
**Назначение:** Быстрая сборка с минимальным набором импортов  
**Файлы импортов:** 15 критических импортов  
**Параметры:** Оптимизирована для скорости  
**Время сборки:** ~2-3 минуты  

**Использование:**
```powershell
cd g:\CODING\nAUDIT
v.naudit\Scripts\python build_exe_fast.py
```

## 🐛 Решение проблем

### Проблема: "PyInstaller не найден"
**Решение:**
```powershell
v.naudit\Scripts\pip install PyInstaller --upgrade
```

### Проблема: "Сборка слишком долго"
**Решение:** Используйте `build_exe_fast.py` вместо `build_exe_v2_1.py`

### Проблема: "Недостаточно памяти"
**Решение:**
1. Закройте ненужные приложения
2. Перезагрузитесь
3. Используйте `build_exe_fast.py`

### Проблема: ".exe не запускается"
**Решение:**
1. Проверьте размер файла (210-230 МБ)
2. Запустите из PowerShell для просмотра ошибок:
   ```powershell
   & "g:\CODING\nAUDIT\dist\nAUDIT.exe"
   ```
3. Проверьте наличие .NET Framework
