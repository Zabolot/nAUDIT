## 📋 Типичный рабочий процесс

1. **Запуск приложения**
   - Двойной щелчок на nAUDIT.exe
   - Приложение откроется в отдельном окне

2. **Открытие проекта**
   - Нажмите "File" → "Open Project"
   - Выберите папку проекта для анализа

3. **Анализ проекта**
   - Приложение автоматически проанализирует код
   - Результаты появятся в левой панели

4. **Просмотр результатов**
   - Выберите вкладку "Errors" (Ошибки)
   - Выберите режим просмотра:
     - **Tree View** - традиционное иерархическое древо
     - **Graph View** - интерактивный граф связей ошибок
     - **Split View** - оба режима одновременно

5. **Анализ связей**
   - В режиме Graph можно:
     - Двигать узлы мышкой
     - Приближать/отдалять (колесо мыши)
     - Видеть связи между ошибками
     - Щелчок на узел - переход к ошибке в древе

## 🐛 Решение проблем

### Проблема: Приложение не запускается
**Решение:**
1. Убедитесь, что файл nAUDIT.exe не повреждён
2. Попробуйте перезагрузить компьютер
3. Откройте PowerShell и введите: `& "G:\CODING\nAUDIT\dist\nAUDIT.exe"`

### Проблема: Медленная работа при анализе больших проектов
**Решение:**
1. Закройте ненужные приложения
2. Убедитесь, что достаточно памяти (4+ GB)
3. Попробуйте анализировать проект по частям

### Проблема: Граф не загружается в режиме GRAPH
**Решение:**
1. Убедитесь, что проект содержит ошибки
2. Переключитесь на режим TREE, затем обратно на GRAPH
3. Попробуйте перезагрузить приложение
