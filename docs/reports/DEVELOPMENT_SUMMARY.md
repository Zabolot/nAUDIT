## 🚀 Как использовать

### Windows
```powershell
# Быстрый старт
.\run_naudit.ps1

# Или сборка .exe
.\build_exe.ps1
```

### Linux/macOS
```bash
# Быстрый старт
chmod +x run_naudit.sh
./run_naudit.sh
```

### Все ОС
```bash
# Запуск GUI
naudit-gui

# Запуск CLI
naudit --module . --report-level full
```
