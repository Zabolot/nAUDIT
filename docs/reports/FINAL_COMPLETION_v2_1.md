## 📦 ЧТО ПОЛУЧИЛОСЬ

### Три режима просмотра ошибок:

1. **🌳 Дерево** - Иерархическая структура
   - Левая панель: список папок и файлов
   - Средняя панель: файлы с ошибками
   - Правая панель: детали каждой ошибки

2. **🕸️ Граф** - Интерактивная визуализация
   - Узлы = файлы проекта
   - Размер узла = количество строк кода
   - Цвет узла = максимальная серьезность ошибок
   - Число на узле = количество ошибок
   - Интерактивность: перемещение, зум, панировка

3. **📊 Разделённый** - Оба одновременно
   - Дерево слева (50%)
   - Граф справа (50%)
   - Полный контроль над обоими видами

### Управление:

- 🔍 Фильтр по серьезности ошибок
- 📐 Масштабирование узлов (50-200%)
- 🏷️ Переключение меток
- 🔗 Переключение связей между файлами
- 🔄 Кнопка обновления графа
