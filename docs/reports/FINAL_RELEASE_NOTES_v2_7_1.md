4. ✅ **Иерархическая групировка облаков**
   - Узлы группируются по папкам

   - Реальная иерархия вместо одного облака

   - Выбор в дереве выделяет узел в графе

   - Работает во всех режимах (TREE, GRAPH, SPLIT)

### QThread-based Рендеринг
```python
class GraphRenderThread(QThread):
    progress = pyqtSignal(int, str)    # Live прогресс
    finished = pyqtSignal(str)         # HTML готов
    error = pyqtSignal(str)            # Ошибка
    
    # Асинхронный рендер без блокировки UI
    # Поддержка Plotly (CDN) и PyVis (интерактив)
```
