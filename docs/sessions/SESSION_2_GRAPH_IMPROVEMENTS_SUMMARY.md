## 🚀 Новые возможности

### 1. **Переключение Рендеров**
```
Верхняя панель: [Рендер: Plotly ▼] 
- Plotly (интерактивный)
- PyVis (сетевой)
```

### 2. **Исключение файлов проекта**
```python
EXCLUDE_FOLDERS = {
    '.venv', '__pycache__', '.git', '.pytest_cache',
    'node_modules', 'build', 'dist', '.idea', ...
}
```

### 3. **Цвета по папкам**
- `gui/` → Синие узлы
- `core/` → Зелёные узлы
- `models/` → Фиолетовые узлы
- Остальное → Разнообразные цвета

### 4. **Видимые связи между файлами**
- Серые линии = импорты между файлами
- Можно включить/отключить чекбоксом

### 5. **Параметры конфигурации**
```python
GRID_SPACING = 25.0        # Расстояние между облаками
CLOUD_RADIUS = 3.0         # Радиус спирали
MIN_NODE_DISTANCE = 3.0    # Увеличение за оборот
```

## 💻 Технические улучшения

