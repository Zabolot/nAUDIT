## Использование

1. **Выберите проект**
   - Нажмите кнопку "Выбрать папку"
   - Укажите папку с Python кодом

2. **Запустите анализ**
   - Нажмите "Начать аудит"
   - Ждите 6 фаз анализа:
     - Сканирование файлов
     - Статический анализ
     - Проверка безопасности
     - Анализ тестов
     - Проверка инфраструктуры
     - Генерация отчёта

3. **Просмотрите результаты**
   - Вкладка "Результаты" показывает:
     - 📊 Рейтинг качества кода
     - 📈 Статистику по типам ошибок
     - 📉 ASCII-графики
     - 📝 Все обнаруженные проблемы

4. **Экспортируйте отчёт**
   - Кнопка "Экспорт отчёта" сохраняет:
     - `audit_report_TIMESTAMP.json` (данные)
     - `audit_report_TIMESTAMP.html` (красивый отчёт)
   - Файлы в папке `.audit_results/reports/`

## Формула рейтинга

```
rating = 10.0 - (code_issues × 0.3) - (security_issues × 0.8) + coverage_bonus
```

Результат: **1-10**
- 🟢 8-10: Отличный код
- 🟠 6-7: Требует внимания
- 🔴 <4: Критические проблемы
