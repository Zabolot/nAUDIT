## 🎯 Использование

### 1. Выбор папки для анализа
- Нажать кнопку "Выбрать папку"
- Выбрать корневую папку проекта

### 2. Запуск аудита
- Нажать кнопку "Запустить аудит"
- Ждать завершения (2-5 минут)

### 3. Просмотр результатов
- **Вкладка "Результаты"**: графики, статистика, таблица проблем
- **Вкладка "История"**: прошлые анализы
- **Вкладка "Логи"**: полная диагностика процесса

### 4. Экспорт
- Нажать кнопку "Экспорт"
- Выбрать формат (JSON/HTML)
- Файлы сохранятся в `.audit_results/reports/`

## 🐍 Программное использование

```python
from n_audit.audit_manager_v2 import AuditManager, AuditResult

manager = AuditManager()

def on_result(result: AuditResult):
    print(f"Рейтинг: {result.rating}/10")
    print(f"Ошибок кода: {result.code_issues}")
    print(f"Уязвимостей: {result.security_issues}")

manager.on_result = on_result
manager.start_audit("/path/to/project")

# Ждём результата (асинхронно)
import time
time.sleep(10)
```
