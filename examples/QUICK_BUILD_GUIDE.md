# nAUDIT v2.1.0 - Быстрый старт сборки .exe

## 🚀 Быстрый запуск

Для сборки нового .exe файла с графовой визуализацией:

### Шаг 1: Откройте PowerShell в папке проекта
```powershell
cd g:\CODING\nAUDIT
```

### Шаг 2: Активируйте виртуальное окружение
```powershell
. .\v.naudit\Scripts\Activate.ps1
```

### Шаг 3: Запустите сборку
```powershell
# РЕКОМЕНДУЕТСЯ - быстрая версия (2-3 минуты)
python build_exe_fast.py

# ИЛИ полная версия (3-5 минут)
python build_exe_v2_1.py
```

## ✅ Проверка результата

Когда сборка завершится, проверьте:

```powershell
# Убедитесь, что файл создан
Get-ChildItem dist\nAUDIT.exe

# Проверьте размер (должно быть ~220 МБ)
(Get-Item dist\nAUDIT.exe).Length / 1MB
```

## 🎯 Новое в v2.1.0 .exe

✨ **Что включено:**
- ✅ Иерархическое древо ошибок (3-уровневая структура)
- ✅ Интерактивный граф визуализации (pyvis + networkx)
- ✅ 3 режима просмотра:
  - **TREE** - Классическое иерархическое древо
  - **GRAPH** - Интерактивная граф визуализация
  - **SPLIT** - Одновременный просмотр обоих режимов

## ⚡ Советы по оптимизации

### Если сборка идёт долго:
1. Используйте `build_exe_fast.py`
2. Закройте другие приложения
3. Убедитесь, что нет других Python процессов

### Если нужна максимальная компатибильность:
1. Используйте `build_exe_v2_1.py`
2. Это займёт дольше, но будет полнее

### Для продакшена:
```powershell
# Используйте быструю версию - она проверена и оптимизирована
python build_exe_fast.py
```

## 🆘 Помощь

**Частые ошибки:**

| Ошибка | Решение |
|--------|---------|
| `PyInstaller не найден` | `pip install PyInstaller` |
| `Python не найден` | Используйте полный путь: `v.naudit\Scripts\python` |
| `Недостаточно памяти` | Закройте другие приложения |
| `Диск полный` | Удалите папку `build/` перед сборкой |
