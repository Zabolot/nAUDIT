# nAUDIT v2.1.0 - БЫСТРАЯ СПРАВКА

## ЧТО НОВОГО В ВЕРСИИ 2.1.0

### 1. ГРАФ-ВИЗУАЛИЗАЦИЯ
- Интерактивная сетевая визуализация всех файлов проекта
- Узлы = файлы, размер = строки кода, цвет = серьезность ошибок
- Управление: фильтр, масштаб, метки, связи

### 2. ТРИ РЕЖИМА ПРОСМОТРА
- Дерево: иерархическая структура проекта
- Граф: интерактивная визуализация связей между файлами
- Разделённый: оба одновременно (дерево слева 50%, граф справа 50%)

### 3. ПОЛНАЯ ИНТЕГРАЦИЯ
- Все три режима находятся в одной вкладке "Ошибки"
- Кнопки для переключения между режимами
- Синхронизированные данные между компонентами

## ИСПОЛЬЗОВАНИЕ ГРАФ-ВИЗУАЛИЗАЦИИ

1. Откройте приложение nAUDIT
2. Выберите проект и запустите аудит
3. Перейдите на вкладку "Ошибки"
4. Выберите режим просмотра:
   - "Дерево" - иерархическая структура файлов
   - "Граф" - интерактивная визуализация
   - "Оба" - обе визуализации одновременно
5. Управляйте графом:
   - Фильтр: выбрать минимальную серьезность ошибок
   - Масштаб: 50-200% (ползунок)
   - Метки: показать/скрыть имена файлов
   - Связи: показать/скрыть рёбра между файлами
   - Обновить: кнопка для перерендеринга

## СИСТЕМА ЦВЕТОВ В ГРАФЕ

Цвет узла зависит от максимальной серьезности ошибок в файле:

CRITICAL (Критические)  -> красный (#ff4444)
HIGH (Высокие)          -> оранжевый (#ff9900)
MEDIUM (Средние)        -> жёлтый (#ffcc00)
LOW (Низкие)            -> зелёный (#44dd44)

Размер узла пропорционален количеству строк кода в файле.

## ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

1. Граф не отображается:
   - Проверьте: pip install PyQt6-WebEngine
   - Запустите: python final_check_v2_1.py
   - Нажмите кнопку обновления графа

2. Чёрный экран в режиме графа:
   - Подождите 2-3 секунды после переключения
   - Нажмите кнопку обновления графа
   - Проверьте размер проекта (большие проекты > 500 файлов медленнее)

3. Узлы наслаиваются:
   - Используйте физику графа (кнопка внизу графа)
   - Нажмите кнопку обновления для новых позиций
   - Перемещайте узлы мышкой

4. Приложение не запускается:
   - Запустите: python final_check_v2_1.py
   - Проверьте все зависимости
   - Смотрите docs/GRAPH_VISUALIZATION_GUIDE.md
