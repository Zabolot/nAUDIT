## За 2 минуты до работы

### 1️⃣ Запуск

```cmd

```

- Откроется GUI окно
- Нажать "Load Project"
- Выбрать папку с исходниками


## 🎮 Управление

### Граф (справа)

| Действие | Результат |
|----------|-----------|
| **Скролл** | Zoom in/out |
| **Клик на узел** | 🔍 Выделить в дереве |
| **Drag узла** | Перемещение |
| **Двойной клик** | 📂 Открыть папку |

### Дерево (слева)

| Действие | Результат |
|----------|-----------|
| **Клик файла** | 📍 Фокус на графе |
| **Expand папка** | Показать содержимое |
| **Context menu** | Больше опций |

## 📊 Что видится в графе

``` text
Большие облака = папки
     ↓
🔵 Узлы = файлы
     ↓
➤ Связи = импорты между файлами

Цвета:
🔴 Red      = Ошибки/проблемы
🟡 Yellow   = Предупреждения
🟢 Green    = OK
🔵 Blue     = Фокус/выделено
```

## 🐛 Если не работает

### Белый лист в графе?

``` bash
✅ Обновить: F5 в графе
✅ Перезагрузить: Закрыть/открыть проект
✅ Перезапустить exe
```

### Нет связей между файлами?

``` bash
✅ Проверить: Файлы с правильным расширением .py
✅ Убедиться: Импорты указаны правильно
✅ Пересканировать: Перезагрузить проект
```

### Exe не запускается?

``` bash
✅ Проверить: dist\nAUDIT.exe существует
✅ Перестроить: python build_exe_v2_4.py
```
