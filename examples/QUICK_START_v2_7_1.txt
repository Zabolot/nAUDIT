## 📍 Where Are the Logs?

**Windows:**
```powershell
# Open log folder
explorer $env:USERPROFILE\.naudit\logs

# Or view latest log:
Get-ChildItem $env:USERPROFILE\.naudit\logs -Filter "*.log" | Sort-Object LastWriteTime -Descending | Select-Object -First 1 | ForEach-Object { Get-Content $_.FullName -Tail 30 }
```

**Linux/macOS:**
```bash
# View logs
ls -la ~/.naudit/logs/

# View latest
tail -30 ~/.naudit/logs/naudit_*.log
```

## 🆘 Troubleshooting Quick Guide

### "Program won't start"
```powershell
# Verify components
python diagnose_v2_7.py

# Check logs for errors
Get-Content $env:USERPROFILE\.naudit\logs\naudit_*.log | Select-String ERROR
```

### "Analysis crashed"
```powershell
# View crash details
tail -100 $env:USERPROFILE\.naudit\logs/naudit_*.log | grep ERROR
```

### "Logs not created"
```powershell
# Create log directory
mkdir $env:USERPROFILE\.naudit\logs -Force

# Try again
python diagnose_v2_7.py
```

### "Errors not showing"
```powershell
# Check if issues were found
Get-Content $env:USERPROFILE\.naudit\logs\naudit_*.log | Select-String "Found code_issues"

# Check parsing
Get-Content $env:USERPROFILE\.naudit\logs\naudit_*.log | Select-String "Error processing"
```
