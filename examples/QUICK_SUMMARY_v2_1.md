## 🚀 Как использовать

```bash
# Запустить приложение
python -m n_audit.gui.main_app

# Или через скрипт запуска
python quick_start_graph_viz.py
```

**В приложении:**
1. Выберите проект и запустите аудит
2. Перейдите на вкладку "🌳 Ошибки"
3. Выберите режим: 🌳 Дерево | 🕸️ Граф | 📊 Оба
4. Управляйте графом: фильтр, масштаб, метки, связи

---

## 🏗️ Архитектура

```
ErrorVisualizationWidget
├── 🌳 Дерево → ErrorTreeWidget (иерархия файлов)
├── 🕸️ Граф → GraphVisualizerWidget (pyvis визуализация)
└── 📊 Оба → Split View (50/50)
```

**Система цветов узлов в графе:**
- 🔴 CRITICAL → красный
- 🟠 HIGH → оранжевый
- 🟡 MEDIUM → жёлтый
- 🟢 LOW → зелёный
