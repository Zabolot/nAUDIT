# Тестовый проект с различными типами ошибок для проверки nAUDIT v2.7.1

## Структура проекта:
- src/file_with_syntax_error.py - Синтаксическая ошибка (незакрытая скобка)
- src/file_with_import_errors.py - Ошибки импорта (несуществующие модули)
- src/file_with_type_errors.py - Ошибки типов (type hints mismatch)
- src/clean_file.py - Чистый файл без ошибок

## Цель тестирования:
1. Проверить, что программа не вылетает при анализе проекта с ошибками
2. Убедиться, что все ошибки отображаются в дереве
3. Проверить что логи содержат детальную информацию
4. Убедиться что GPU уровень оптимизации отображается

## Ожидаемые ошибки:
- Синтаксические ошибки: 1 (в file_with_syntax_error.py)
- Ошибки импорта: 3 (в file_with_import_errors.py)
- Ошибки типов: 2 (в file_with_type_errors.py)

Всего: 6 ошибок
